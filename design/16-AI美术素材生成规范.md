# 16 - AI 美术素材生成规范

> ⭐ 本文档是《命》所有美术素材的**生成宪法**。AI 生成最大的风险是"风格散乱"，因此第一节"风格锚定"是所有素材必须遵守的铁律。无论用哪个工具、生成什么素材，都要先回头看第一节。
>
> **美术方向（v0.3 确定）：扁平手绘 2.5D，AI 生成（即梦/可灵/通义/Midjourney），Spine 骨骼动画。**

> ⚠️ **v0.3.2 重要更新**：经测试发现"AI 生成的整张场景图无法当游戏地图用"（角色会飘在上面、无法区分可走路径、无法局部修改）。
>
> **本文档第四节（场景生成规范）和第五节中关于"场景"的部分已作废**，改用 **17 号文档** 的"地砖+物件素材包 + Godot TileMap 拼装"工作流。
>
> **本文档仍然有效的部分**：第一节风格锚定、第三节角色规范、第五节 CG 规范、第六节 UI 规范、第七节 AI 技巧、第九节 MVP 优先清单中的角色/CG/UI 部分。

## 一、风格锚定（最重要的章节，反复看）

### 1.1 一句话风格

> **暖色调扁平手绘插画，俯视斜 45° 2.5D 透视，柔和光影，克制留白，像一本中国乡村题材的绘本。**

### 1.2 风格参考关键词（中文）

把以下关键词放进每次生成的提示词开头，保证风格统一：

```
扁平手绘插画，暖色调，2.5D 俯视斜45度透视，柔和光影，
柔和平涂上色，没有描边（或极细描边），绘本质感，
中国乡村/小镇题材，克制内敛，留白，治愈温暖
```

### 1.3 风格参考关键词（英文，给 Midjourney 用）

```
flat hand-drawn illustration, warm color palette, 2.5D top-down 
isometric perspective, soft lighting, cel shading without outline, 
storybook art style, Chinese countryside / small town, minimalist, 
warm and melancholic, cozy
```

### 1.4 风格的"绝对禁止项"（防止 AI 跑偏）

❌ **禁止**：写实风格、3D 渲染、油画厚涂、赛博朋克、霓虹高饱和、
   像素颗粒、二次元大眼萌系、欧美卡通粗描边、Q 版大头

❌ **禁止**：复杂背景细节堆砌（要克制留白）

❌ **禁止**：鲜艳刺眼的纯色（饱和度统一压低）

### 1.5 色彩规范（所有素材共用）

| 用途 | 色值 | 说明 |
|------|------|------|
| 主背景 | `#F5EFE0` 米暖白 | 大面积底色 |
| 次背景 | `#E8DCC4` 浅卡其 | 场景阴影区 |
| 主线条 | `#3D3530` 深棕灰 | 替代纯黑，更暖 |
| 暖色强调 | `#C97B4A` 暖橙棕 | 木质、夕阳 |
| 冷色强调 | `#6B8E9E` 雾霾蓝 | 窗户、天空 |
| 绿植 | `#8FA96B` 灰绿 | 树木草地（不鲜艳） |
| 积极情绪 | `#D4A574` 暖黄 | 童年、幸福 |
| 消极情绪 | `#7A6B5D` 灰棕 | 中年、沉重 |

### 1.6 阶段色调演变（场景换皮的核心）

同一张地图，不同人生阶段用不同色调滤镜，**这是"时间流逝"的视觉语言**：

| 阶段 | 色调倾向 | 色温 | 情绪 |
|------|---------|------|------|
| 童年 | 暖黄偏亮 | 暖 | 温暖、纯真 |
| 少年 | 灰蓝偏冷 | 中性 | 压抑、迷茫 |
| 青年 | 灰白偏冷 | 中性偏冷 | 现实、压力 |
| 中年 | 深灰偏暗 | 冷 | 沉重、疲惫 |
| 老年 | 暖灰偏暗 | 暖 | 回忆、释然 |

> **生成策略**：核心场景用"童年暖黄"版本生成为基准，其余阶段在引擎里用 `ColorRect` 色调滤镜叠加实现，**不需要每个阶段都重新生成整套素材**。这是省工作量关键。

## 三、角色素材生成规范

### 3.1 主角立绘

**主角不画明确五官**（代入感设计，见 12 号文档）。生成时强调"轮廓、姿态、氛围"。

#### 生成要求

| 维度 | 要求 |
|------|------|
| 尺寸 | 竖版 1024×1536（立绘用） |
| 视角 | 正面或四分之三侧面，全身 |
| 背景 | 纯色或透明（`#F5EFE0`） |
| 五官 | **模糊处理/背光/低头**，不要清晰五官 |
| 姿态 | 见下表各阶段 |

#### 各年龄阶段立绘姿态

| 阶段 | 体形 | 姿态 | 服装 | 情绪 |
|------|------|------|------|------|
| 童年(7-12) | 瘦小、个矮 | 站立微倾、好奇抬头 | 旧 T 恤短裤/校服 | 活泼 |
| 少年(13-18) | 偏瘦、抽高 | 双手插兜、微低头 | 校服、帆布鞋 | 沉默迷茫 |
| 青年(18-30) | 标准、偏瘦 | 步伐急促、单肩包 | 衬衫/T恤+牛仔裤 | 焦虑向前 |
| 中年(30-50) | 微沉、肩沉 | 微弯、手垂 | 夹克/衬衫皱 | 疲惫 |
| 老年(50-80) | 佝偻、瘦 | 拖步、拄杖或背手 | 旧外套 | 平静释然 |

#### 提示词模板（主角童年立绘）

```
扁平手绘插画，全身人物立绘，一个7岁中国乡村男孩，
瘦小身形，穿着旧T恤和短裤，站立姿态微微前倾好奇地抬头，
没有清晰五官（背光/面部留白），暖黄暖橙色调，柔和平涂上色，
绘本质感，纯色背景，竖构图
```

#### 提示词模板（主角少年立绘）

```
扁平手绘插画，全身人物立绘，一个16岁中国少年，偏瘦身形正在抽高，
双手插在校服口袋里，微微低头，没有清晰五官，
灰蓝色调，柔和平涂上色，绘本质感，纯色背景，竖构图
```

### 3.2 主角行走图（关键，决定能否做成动画）

**因为 AI 无法稳定生成逐帧动画，所以行走图用两种方案，选其一：**

#### 方案 A：四方向静帧（推荐 MVP）

让 AI 生成"四方向站立参考图"，然后在 Aseprite/PS 里手动做简单行走帧。

**生成要求：**
- 横版 2048×512，分成 4 格（前/后/左/右）
- 每个方向一个标准站立姿势
- 纯色背景，便于抠图

**提示词模板：**
```
扁平手绘插画，同一个7岁中国乡村男孩的四方向视图，
从左到右依次是：正面、背面、左侧面、右侧面，
每个都是标准站立姿势，没有清晰五官，
暖色调平涂上色，纯色背景，横向四宫格布局
```

#### 方案 B：Spine 骨骼动画（推荐完整版）

让 AI 生成"分层拆件图"——角色身体各部件分开，导入 Spine 做骨骼动画。

**生成要求：**
- 角色正面站立，肢体自然张开（不重叠）
- 分层：头、躯干、左臂、右臂、左腿、右腿
- AI 很难一次出分层图，**实际操作**：AI 出正面整体图 → 在 PS 里手动拆件 → Spine 绑骨

> **MVP 用方案 A（四方向静帧 + 简单 2-3 帧行走），完整版升级方案 B（Spine）。** 这是务实的路径。

|------|------|---------|------|------|

| **小芳** | 女 | 乖巧、马尾辫、酒窝、清秀 | 碎花裙/校服 | 温柔 |
| **阿强** | 男 | 黑壮、结实、方脸 | 旧 T 恤、布鞋 | 老实 |

```
偏瘦、头发蓬乱、有点鼻涕、表情调皮不羁，
```


### 3.4 NPC 多版本变体（同一 NPC 不同人生状态）

这是核心难点——**同一个 NPC，不同人生版本外观要变，但辨识度要保留**。

**策略：固定"辨识特征"不变，只改变"状态特征"。**

以小刚为例（5 个版本，见 15 号文档）：

| 版本 | 不变的辨识特征 | 改变的状态特征 |
|------|--------------|--------------|
| A 打工仔 | 蓬乱头发、瘦 | 晒黑、壮实、穿工装 |
| B 误入歧途 | 蓬乱头发 | 文身、消瘦、眼神凶 |
| C 手艺人 | 蓬乱头发 | 结实、穿围裙、手粗糙 |
| D 早逝 | 蓬乱头发 | 遗照感、黑白/泛黄 |
| E 当兵 | 蓬乱头发→板寸 | 穿军装、挺拔 |

**生成技巧**：先用一个版本定"基础脸"（保留 seed），后续版本在此基础上加修饰词。

```
（在生成A版后）使用相同seed，提示词加入：
"长大后，皮肤晒黑，穿着蓝色工装，眼神疲惫但坚定"
```

## 四、场景素材生成规范

### 4.1 透视与视角（所有场景统一）

**这是场景一致性的命脉，必须所有场景共用同一透视：**

```
俯视斜 45° 等：2.5D isometric perspective / 俯视斜45度透视
```

❌ 绝不能混用：正视图、侧视图、纯俯视图、第一人称

### 4.2 小镇主地图

**这是 MVP 最重要的场景**，玩家大部分时间在这里。

#### 生成要求

| 维度 | 要求 |
|------|------|
| 尺寸 | 横版 3072×1728（宽幅地图） |
| 透视 | 俯视斜 45° 2.5D |
| 内容 | 村口老槐树、小卖部、土路、几栋民房、远处田野山丘、小河 |
| 光照 | 暖黄午后阳光（童年版基准） |
| 留白 | 大面积天空和田野，不堆砌 |
| 季节 | 夏末初秋（绿意+一点黄） |

#### 提示词模板

```
扁平手绘插画，2.5D俯视斜45度透视，中国北方乡村小镇全景，
画面中心一棵大槐树，旁边一间小卖部，几栋土房和砖房，
土路蜿蜒，远处是田野和低矮山丘，一条小河，
夏末午后暖黄阳光，柔和平涂上色，大量天空留白，
绘本质感，克制内敛，横版宽幅构图
```

### 4.3 室内场景（节点进入）

每个室内场景一张，**透视与主图一致**（俯视斜 45°）。

#### MVP 需要的室内

| 场景 | 内容 | 氛围 |
|------|------|------|
| 家（客厅） | 旧沙发、方桌、电视、贴画、窗户 | 温暖但简陋 |
| 学校教室 | 课桌椅排列、黑板、国旗、窗户 | 压抑中带希望 |
| 老槐树特写 | 大树、秋千、树下长椅 | 自由、回忆 |
| 小卖部 | 货架、柜台、零食、大壮家人 | 烟火气 |

#### 提示词模板（家-客厅，农村普通家庭）

```
扁平手绘插画，2.5D俯视斜45度透视，中国乡村普通家庭的客厅，
旧布沙发、一张方桌、老式电视、墙上贴画、一扇窗透进暖光，
简陋但温馨，暖黄午后色调，柔和平涂上色，绘本质感，留白
```

### 4.4 城市场景（青年段，MVP 不做）

| 场景 | 内容 |
|------|------|
| 出租屋 | 狭小、单人床、电脑、外卖盒（孤独） |
| 公司工位 | 隔间、电脑、堆文件（压抑） |
| 相亲角 | 公园、贴满相亲信息的展板 |
| 医院 | 白色、病床、走廊 |

**色调比乡村冷**，呼应"进城后失去温度"。

### 4.5 场景分层（2.5D 纵深关键）

为了让 2.5D 有空间感，场景最好分层。**AI 生成时分层很难，实操方案：**

- AI 出整体场景图
- 在 PS 里手动拆 2-3 层（前景树木/中景建筑/远景天空）
- 导入 Godot 用 `ParallaxBackground` 视差滚动

> 这是 AI + 手工的结合点，纯靠 AI 拿不到分层。

## 五、CG 素材生成规范

### 5.1 CG 的作用

CG 是**情感爆发点**的视觉强化，用在大场面：
- 序章混沌
- 命运之骰
- 高考考场
- 小刚告别
- 毕业典礼
- 婚礼
- 父母离世
- 老年回望
- 结局

### 5.2 CG 与场景的区别

| 维度 | 场景 | CG |
|------|------|-----|
| 用途 | 玩家走在里面 | 剧情过场展示 |
| 透视 | 俯视 45°（可走动） | **自由**（电影感构图） |
| 视角 | 固定 | 多变（特写/全景/俯瞰） |
| 尺寸 | 大幅地图 | 16:9 单张 |

### 5.3 CG 生成要求

| 维度 | 要求 |
|------|------|
| 尺寸 | 1920×1080（16:9） |
| 构图 | 电影感，有主体有留白 |
| 情绪 | 强（这是情感点） |
| 文字 | **无文字**（文字由引擎叠加，避免 AI 乱写字） |

### 5.4 MVP 关键 CG 清单

#### CG-01：序章·混沌

```
扁平手绘插画，极简画面，纯黑背景中一个微弱的光点正在汇聚，
画面中央逐渐显现一颗骰子的轮廓，大量留白，
深邃神秘，绘本质感，16:9横构图
```

#### CG-02：命运之骰

```
扁平手绘插画，一颗巨大的骰子悬浮在暖黄色虚空中，
骰子每一面隐约显现不同的生活场景（破屋/公寓/别墅），
命运感、宿命感，柔和暖光，绘本质感，16:9横构图
```

#### CG-03：小刚告别（关键泪点）

```
扁平手绘插画，中国乡村小镇的汽车站，一个少年背着编织袋准备上车，
另一个少年站在车下，两人对视，背景是夕阳和土路，
离别感、怅然若失，暖橙色调夕阳，柔和平涂，绘本质感，16:9横构图，
人物没有清晰五官，用背影和姿态表达情绪
```

#### CG-04：高考考场

```
扁平手绘插画，中国高考考场，整齐的课桌排列，学生们低头答题，
窗外是六月的阳光，黑板上写着"沉着冷静"，
压抑紧张又充满希望，灰蓝色调，柔和平涂，绘本质感，16:9横构图
```

### 5.5 完整版 CG 清单（按阶段）

| 阶段 | CG | 情感 |

## 七、AI 生成实操技巧（重要）

### 7.1 风格一致性的核心：固定提示词前缀

**所有素材的提示词，开头必须加这一段"风格锚"：**

```
【风格锚 - 必加】
扁平手绘插画，暖色调，柔和平涂上色，没有描边，
绘本质感，克制留白，中国乡村题材
```

无论是角色、场景、CG，先加这段，再加具体内容。

### 7.2 角色一致性的核心：固定 seed

**同一个角色（如小刚），所有版本都用同一个 seed 生成。**

- 即梦/可灵：记录生成参数，多次生成时复用
- Midjourney：用 `--seed 12345` 固定
- 通义：用"参考图"功能，把第一张作为参考

### 7.3 多版本角色的"基础脸"策略

1. 先生成角色的"基础版"（如小刚 10 岁童年版）
2. 把这张作为"参考图/垫图"
3. 后续版本在此基础上加修饰词：
   - "长大后、晒黑、穿工装" → 打工版
   - "文身、消瘦、眼神凶" → 误入歧途版

### 7.4 场景透视一致性的核心：固定"2.5D 俯视斜45度"

**每次场景生成都要带上这句**，否则透视会乱。

### 7.5 避免 AI 写中文字

AI 生成的中文字几乎都是错的。**所有需要文字的地方（对联、招牌、黑板字）一律让 AI 生成空白/英文，再在 PS 里手动加中文。**

### 7.6 抠图与透明背景

AI 工具大多能输出透明背景 PNG（角色立绘用）。如果不能：
- 生成时要求"纯色背景（如纯白/纯绿）"
- 用 PS 的"色彩范围"或 removebg 一键抠图

### 7.7 尺寸与放大

- AI 出图通常 1024×1024，**用工具的"高清放大"功能放大到所需尺寸**
- 大地图（3072×1728）可能需要拼接：分别生成左右两半，PS 拼接

### 7.8 批量生成的清单化管理

**建议建一个素材表（Excel/Notion），每条记录：**
- 素材 ID（如 CHAR_xiaogang_vA）
- 类别（角色/场景/CG/UI）
- 提示词
- seed
- 文件名
- 状态（待生成/已生成/已入库/已替换）

否则后期会乱。

## 十、法律与版权注意

### 10.1 AI 生成素材的版权

- **国内**：AI 生成内容目前版权归属有争议，商用建议保留生成记录
- **Steam**：Steam 已允许 AI 生成内容上架，但需在商店页声明"使用了 AI"
- **建议**：发布前在 Steam 页面勾选 AI 使用声明

### 10.2 避免侵权

- ❌ 提示词里**不要写**具体游戏名/电影名/艺术家名（如"星露谷风格""吉卜力"）
- ❌ 不要生成有明显商标的元素
- ✅ 用通用风格描述（"扁平手绘""绘本风"）

## 十一、风险与应对

| 风险 | 应对 |
|------|------|
| 风格不统一 | 严格遵守第一节风格锚 + seed 复用 |
| 角色多版本不像同一人 | 固定基础脸，状态特征叠加 |
| AI 写错中文 | 让 AI 出空白，PS 手动加字 |
| 行走动画做不出来 | MVP 用四方向静帧 + 简单帧，完整版上 Spine |
| 场景透视乱 | 每次必带"2.5D俯视斜45度" |
| 素材太多管理混乱 | 建素材表 + 严格命名 |

## 十二、本节小结

AI 美术生成的核心三件事：

1. **风格锚定**（第一节）——所有素材共用的风格宪法
2. **一致性策略**（第七节）——seed 复用 + 风格前缀 + 基础脸
3. **分批生成**（第九节）——先验证 3 张定风格，再批量做

**第一步行动：生成第一批 3 张素材（小镇主图 + 主角立绘 + 小刚立绘），看风格是否统一满意，再继续。**
