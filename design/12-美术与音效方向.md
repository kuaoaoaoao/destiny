# 12 - 美术与音效方向

---

## 一、美术风格

### 1.1 整体风格选择

**推荐风格：极简插画 + 像素元素**

**理由：**
- 符合游戏的克制、内敛气质
- 制作成本相对较低
- 能够突出情感而非视觉
- 适合独立游戏定位

### 1.2 风格特征

**色彩：**
- 整体色调偏灰、偏暖
- 不使用过于鲜艳的颜色
- 用色彩变化表现情绪

**色彩方案：**

| 阶段 | 主色调 | 辅助色 | 说明 |
|------|--------|--------|------|
| 童年 | 暖黄 | 浅蓝、浅绿 | 温暖、纯真 |
| 少年 | 灰蓝 | 白色、浅灰 | 压抑、迷茫 |
| 青年 | 灰色 | 暗蓝、暗绿 | 现实、压力 |
| 中年 | 深灰 | 暗红、暗黄 | 沉重、疲惫 |
| 老年 | 暖灰 | 米白、浅黄 | 回忆、释然 |

**线条：**
- 简洁、流畅
- 不使用过于复杂的线条
- 用留白表现空间

**构图：**
- 大量留白
- 主体居中或偏移
- 用空间表现孤独/自由

### 1.3 场景设计

**场景类型：**

| 场景 | 元素 | 氛围 |
|------|------|------|
| 家 | 家具、窗户、光影 | 温暖/压抑 |
| 学校 | 课桌、黑板、窗户 | 压抑/希望 |
| 公司 | 办公桌、电脑、隔间 | 压抑/疲惫 |
| 医院 | 白色、病床、窗户 | 压抑/悲伤 |
| 养老院 | 窗户、椅子、阳光 | 平静/孤独 |
| 户外 | 天空、树木、道路 | 自由/希望 |

**窗户元素：**
- 窗户是贯穿游戏的重要元素
- 童年：窗外是阳光
- 少年：窗外是天空
- 青年：窗外是城市
- 中年：窗外是黑夜
- 老年：窗外是回忆

### 1.4 角色设计

**设计原则：**
- 不设计具体的面部特征
- 用轮廓和姿态表现情绪
- 让玩家代入自己的形象

**角色表现：**
- 童年：小小的身影
- 少年：略高的身影
- 青年：站立的身影
- 中年：微弯的身影
- 老年：佝偻的身影

**姿态语言：**

| 姿态 | 含义 |
|------|------|
| 站立 | 正常/自信 |
| 坐着 | 疲惫/思考 |
| 蹲着 | 沮丧/无助 |
| 奔跑 | 希望/焦虑 |
| 回头 | 回忆/不舍 |
| 背影 | 孤独/前行 |

## 二、UI设计

### 2.1 整体风格

**风格：极简、克制、留白**

- 大量留白
- 文字为主
- 按钮简洁
- 不使用过多装饰

### 2.2 字体选择

| 场景 | 字体 | 说明 |

| 旁白 | 楷体/手写体 | 亲切、温暖 |
| 数字 | DIN/Roboto | 清晰、现代 |

## 三、音效设计

### 3.1 整体风格

**风格：环境音 + 钢琴 + 留白**

- 不使用过于复杂的音乐
- 用环境音营造氛围
- 用钢琴点缀情绪
- 大量留白

### 3.2 环境音设计

| 场景 | 环境音 | 说明 |
|------|--------|------|
| 童年 | 鸟叫、风声、远处的孩子笑声 | 温暖、纯真 |
| 少年 | 蝉鸣、翻书声、钟表声 | 压抑、紧张 |
| 青年 | 城市噪音、地铁声、键盘声 | 现实、忙碌 |
| 中年 | 电视声、孩子哭声、沉默 | 疲惫、沉重 |
| 老年 | 风声、钟表声、远处的声音 | 平静、孤独 |

### 3.3 音乐设计

**音乐风格：**
- 钢琴为主
- 简单、克制
- 不喧宾夺主
- 留白多于填充

**音乐情绪：**

| 情绪 | 音乐特征 | 使用场景 |
|------|---------|---------|
| 温暖 | 简单的钢琴旋律，大调 | 童年、幸福时刻 |
| 带有希望 | 钢琴+弦乐，逐渐上行 | 毕业、结婚 |
| 焦虑 | 不和谐音，节奏不规律 | 考试、面试 |
| 沉重 | 低音钢琴，缓慢 | 中年、压力 |
| 悲伤 | 钢琴独奏，缓慢 | 离别、去世 |
| 释然 | 钢琴+环境音，温暖 | 接受、释然 |

### 3.4 特殊音效

| 音效 | 使用场景 | 说明 |
|------|---------|------|
| 心跳声 | 重要时刻 | 紧张、期待 |
| 呼吸声 | 安静时刻 | 存在感 |
| 钟表声 | 时间流逝 | 岁月 |
| 风声 | 老年、回忆 | 孤独、释然 |
| 雨声 | 悲伤时刻 | 情绪烘托 |
| 笑声 | 童年、幸福 | 温暖 |
| 哭声 | 悲伤时刻 | 情绪释放 |

## 四、动效设计

### 4.1 过渡动效

| 过渡类型 | 动效 | 说明 |
|---------|------|------|
| 时间流逝 | 画面逐渐变暗再变亮 | 岁月流逝 |
| 场景切换 | 淡入淡出 | 平稳过渡 |
| 重要事件 | 画面静止，文字出现 | 强调 |
| 选择出现 | 文字逐字出现 | 引导注意 |

### 4.2 选择动效

| 动效 | 说明 |
|------|------|
| 选项出现 | 文字从下方滑入 |
| 选项选中 | 选项变亮，其他变暗 |
| 选项确认 | 轻微的点击音效 |

### 4.3 数值变化动效

| 动效 | 说明 |
|------|------|
| 数值增加 | 数字向上飘，颜色变绿 |
| 数值减少 | 数字向下飘，颜色变红 |
| 数值警告 | 数字闪烁 |

## 五、平台适配

### 5.1 PC端

**分辨率：** 1920×1080（支持其他分辨率）
**操作方式：** 鼠标点击
**界面布局：** 居中，大量留白

### 5.2 移动端

**分辨率：** 适配各种手机屏幕
**操作方式：** 触摸点击
**界面布局：** 全屏，文字适中

### 5.3 主机端

**分辨率：** 1920×1080 / 4K
**操作方式：** 手柄操作
**界面布局：** 适配电视屏幕
