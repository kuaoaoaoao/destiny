# 数值面板 UI

> **Status**: Designed
> **Author**: Claude + User
> **Last Updated**: 2026-06-15
> **Implements Pillar**: Pillar 2（没有好坏，只有不同）— 数值展示无评判

## Overview

**数值面板 UI**是游戏的展示层，负责显示六大数值。数值面板应该简洁、直观，不评判数值高低。

**技术层面**：Control 节点，显示六大数值的当前值和变化。支持 +/- 动画。

**玩家体验层面**：玩家看到自己的人生状态——健康、心理、教育、金钱、社交、家庭。数值不是「分数」，是「维度」。

**核心设计原则**：数值面板应该「客观」——只显示数值，不评判好坏。

## Detailed Design

### Core Rules

**1. 数值面板布局**

```
┌─────────────────────┐
│ 健康  ████████░░ 80 │
│ 心理  ██████░░░░ 60 │
│ 教育  ██████████ 100│
│ 金钱  ████░░░░░░ 40 │
│ 社交  ███████░░░ 70 │
│ 家庭  █████████░ 90 │
└─────────────────────┘
```

**2. 数值显示规则**
- 按菜单键呼出数值面板
- 显示六大数值的当前值和进度条
- 数值变化时显示 +/- 动画
- 关闭菜单时隐藏

### Interactions with Other Systems

| 系统 | 数据流向 | 接口 |
|------|---------|------|
| **命运系统** ← | 数值状态 → UI 显示 | 查询接口：`get_stats()` |

## Formulas

无复杂公式。

## Edge Cases

- **如果数值变化频繁**：合并动画，避免闪烁
- **如果数值为 0 或 100**：进度条显示为空或满

## Dependencies

依赖：
- **命运系统**：查询数值状态

## Tuning Knobs

| 旋钮 | 默认值 | 范围 | 说明 |
|------|--------|------|------|
| stats_animation_duration | 0.5s | 0.3–1.0 | 数值变化动画时间 |

## Visual/Audio Requirements

- 进度条的颜色（健康绿、心理蓝、教育黄、金钱金、社交橙、家庭红）
- 数值变化的 +/- 动画

## UI Requirements

- 数值面板布局（进度条 + 数值）

## Acceptance Criteria

- GIVEN 按菜单键，WHEN 呼出数值面板，THEN 显示六大数值
- GIVEN 数值变化，WHEN 查看面板，THEN 显示 +/- 动画
