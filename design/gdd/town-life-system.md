# 小镇生活系统

> **Status**: Designed
> **Author**: Claude + User
> **Last Updated**: 2026-06-15
> **Implements Pillar**: Pillar 4（小镇是情感锚点）— 小镇生活是游戏的核心体验

## Overview

**小镇生活系统**是游戏的核心层，负责将所有基础系统组合成「在小镇中过人生」的核心体验。它是 30 秒循环（走动 → 遇 NPC → 触发事件）的整合者。

**技术层面**：协调玩家控制系统、场景管理系统、NPC 日程系统、事件引擎，驱动小镇的日常运转。本身不包含新逻辑，而是组合现有系统。

**玩家体验层面**：玩家在小镇中自由探索，遇到 NPC，触发事件，做选择，感受时间流逝。这就是「过人生」的核心体验。

**核心设计原则**：小镇生活应该「有节奏但不机械」——每天相似但不相同，有规律但有惊喜。

## Player Fantasy

**「我在一个真实的小镇中生活。」**

玩家在小镇中走动时，应该感到自己真的「住」在这里——知道哪里能找到谁，知道什么时候该去哪里，知道这个小镇的每一个角落。小镇不是关卡，是家。

**支柱服务**：直接服务 Pillar 4（小镇是情感锚点）— 小镇是情感的容器。

## Detailed Design

### Core Rules

**1. 单日循环**

```
早晨醒来（家里）
    │
    ▼
自由行动（去学校/找伙伴/去集市）
    │  ┌── 遇到 NPC → 对话/事件
    │  ├── 进入场景 → 小游戏/家庭事件
    │  └── 时间流逝（早→午→晚）
    ▼
夜晚回家睡觉
    │
    ▼
次日 / 或推进到下一关键周
```

**2. 核心循环驱动**
- 玩家移动 → 触发场景交互 → 遇到 NPC → 触发对话/事件 → 做选择 → 数值变化 → 时间推进 → 次日

**3. 小镇事件分布**
- 每天有 3-5 个可触发事件（根据时间和年龄）
- 事件分布在小镇不同位置
- 玩家需要主动探索才能发现所有事件

### Interactions with Other Systems

| 系统 | 数据流向 | 接口 |
|------|---------|------|
| **玩家控制系统** ← | 玩家位置 → 核心循环 | 查询玩家状态 |
| **场景管理系统** ← | 场景切换 → 区域事件 | 信号：`scene_changed` |
| **NPC 日程系统** ← | NPC 位置 → 遇见机会 | 查询 NPC 位置 |
| **事件引擎** ← | 事件触发 → 生活事件 | 信号：`event_triggered` |
| **时间系统** ← | 时间推进 → 日循环 | 查询当前时间 |

## Formulas

每日事件数量公式：
`daily_events = base_events + age_bonus + random_bonus`

| 变量 | 符号 | 类型 | 范围 | 描述 |
|------|------|------|------|------|
| base_events | B | int | 3–5 | 基础每日事件数 |
| age_bonus | A | int | 0–2 | 年龄段加成 |
| random_bonus | R | int | 0–2 | 随机加成 |

## Edge Cases

- **如果一天内玩家没有触发任何事件**：正常推进到次日，不强制触发
- **如果玩家不回家睡觉**：时间自动推进到夜晚，然后跳到次日
- **如果所有可触发事件都已完成**：显示「平静的一天」，正常推进

## Dependencies

依赖：
- **玩家控制系统**：玩家位置和状态
- **场景管理系统**：场景加载和切换
- **NPC 日程系统**：NPC 位置和行为
- **事件引擎**：事件触发和执行
- **时间系统**：时间推进

被以下系统依赖：
- **命运系统**：依赖生活事件修改数值

## Tuning Knobs

| 旋钮 | 默认值 | 范围 | 说明 |
|------|--------|------|------|
| daily_event_base | 3 | 3–5 | 每日基础事件数 |
| exploration_reward | 1.5 | 1.0–2.0 | 探索奖励倍率 |

## Visual/Audio Requirements

- 小镇的日常视觉变化（早晨/白天/傍晚/夜晚）
- NPC 日常行为动画
- 小镇环境音（人声/鸟叫/广播）

## UI Requirements

- 当前位置提示
- 可交互物体提示

## Acceptance Criteria

- GIVEN 玩家在小镇中，WHEN 自由探索，THEN 可以遇到 NPC 并触发事件
- GIVEN 一天结束，WHEN 玩家回家睡觉，THEN 时间推进到次日
- GIVEN 所有事件已完成，WHEN 继续探索，THEN 显示「平静的一天」

## Open Questions

- 小镇事件的密度和分布需要测试调整
- 探索奖励的具体机制需要设计
