# 命运之书 UI

> **Status**: Designed
> **Author**: Claude + User
> **Last Updated**: 2026-06-15
> **Implements Pillar**: Pillar 5（多周目见全貌）— 命运之书记录每段人生

## Overview

**命运之书 UI**是游戏的展示层，负责显示人生记录——关键事件、数值变化、人生轨迹。命运之书是玩家的「人生回忆录」。

**技术层面**：Control 节点，显示人生时间线、关键事件、数值摘要。支持翻页效果。

**玩家体验层面**：玩家翻看自己的人生之书——看到从出生到现在的每一个关键时刻。命运之书是「回忆」，不是「数据」。

**核心设计原则**：命运之书应该「有温度」——不是冷冰冰的数据表，而是温暖的人生记录。

## Detailed Design

### Core Rules

**1. 命运之书内容**

| 部分 | 内容 |
|------|------|
| 封面 | 人生标题（自动生成） |
| 时间线 | 从出生到现在的时间线 |
| 关键事件 | 已触发的关键事件列表 |
| 数值摘要 | 最终六大数值 |
| 伙伴命运 | 伙伴的当前命运状态 |

**2. 命运之书行为**
- 人生结束时自动生成
- 可通过菜单随时查看
- 支持翻页浏览

### Interactions with Other Systems

| 系统 | 数据流向 | 接口 |
|------|---------|------|
| **命运系统** ← | 数值状态 → 书显示 | 查询接口 |
| **人生节点系统** ← | 节点选择 → 事件记录 | 查询接口 |
| **NPC 平行人生系统** ← | 伙伴命运 → 伙伴章节 | 查询接口 |

## Formulas

无复杂公式。

## Edge Cases

- **如果人生记录为空**：显示「空白的人生」
- **如果人生记录过长**：分页显示

## Dependencies

依赖：
- **命运系统**：查询数值状态
- **人生节点系统**：查询节点选择
- **NPC 平行人生系统**：查询伙伴命运

## Tuning Knobs

| 旋钮 | 默认值 | 范围 | 说明 |
|------|--------|------|------|
| page_turn_speed | 0.3s | 0.2–0.5 | 翻页动画时间 |

## Visual/Audio Requirements

- 命运之书的绘本风格
- 翻页动画和音效
- 关键事件的插图

## UI Requirements

- 命运之书布局（封面/时间线/事件/数值/伙伴）
- 翻页交互

## Acceptance Criteria

- GIVEN 人生结束，WHEN 查看命运之书，THEN 显示完整人生记录
- GIVEN 命运之书打开，WHEN 翻页，THEN 显示不同章节
- GIVEN 查看伙伴章节，WHEN 选择伙伴，THEN 显示伙伴命运
