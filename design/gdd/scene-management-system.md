# 场景管理系统

> **Status**: Designed
> **Author**: Claude + User
> **Last Updated**: 2026-06-15
> **Implements Pillar**: Pillar 4（小镇是情感锚点）— 场景是小镇的空间载体

## Overview

**场景管理系统**是游戏的基础层，负责管理室内外场景的加载、切换和过渡。它是小镇生活的空间框架——没有它，世界无法运转。

**技术层面**：管理 Godot 场景文件（.tscn）的加载和卸载，处理室内外切换、区域触发、场景过渡动画。使用 `change_scene_to_file()` 或自定义场景管理器。

**玩家体验层面**：玩家在小镇中自由穿行——从家走到学校，从学校走到老槐树，从小卖部走进室内。场景切换应该是无缝的，玩家感受不到加载。

**核心设计原则**：场景切换应该是「走路穿过一扇门」，不是「传送 loading 画面」。

## Player Fantasy

**「这个小镇是真实存在的。」**

玩家在场景间穿行时，应该感到小镇是一个连贯的空间——从家的院子走到村口的老槐树，从老槐树走到学校操场，每一步都是连续的。室内场景（家、学校、小卖部）是小镇的「内部」，通过门/路口自然进入，不是独立的关卡。

**支柱服务**：直接服务 Pillar 4（小镇是情感锚点）——场景是情感的容器，老槐树、小卖部、车站都是情感符号。

## Detailed Design

### Core Rules

**1. 场景层级结构**

| 层级 | 说明 | 示例 |
|------|------|------|
| **世界地图** | 小镇主地图，包含所有室外区域 | Town.tscn |
| **区域** | 世界地图的子区域，通过触发器进入 | Home.tscn, School.tscn |
| **室内** | 区域的内部场景 | HomeInterior.tscn |

**2. 场景切换规则**
- 室外 → 室内：角色进入 `Area2D` 触发器，播放过渡动画，加载室内场景
- 室内 → 室外：角色走到门口，按交互键，播放过渡动画，返回室外
- 区域切换：角色走到地图边缘或路口，触发区域切换
- 切换时暂停游戏时间（不消耗日内时间）

**3. 场景过渡方式**
- **黑屏过渡**：标准场景切换（0.5 秒黑屏）
- **开门过渡**：室内进出（门打开动画）
- **无感过渡**：同一区域内的子场景切换

**4. 场景状态持久化**
- 每个场景保存自己的状态（NPC 位置、物体状态）
- 场景卸载时序列化状态，重新加载时恢复
- 全局状态（玩家位置、时间）由其他系统管理

### States and Transitions

| 状态 | 描述 | 可转入 |
|------|------|--------|
| **OUTDOOR** | 室外场景 | INDOOR, TRANSITION |
| **INDOOR** | 室内场景 | OUTDOOR, TRANSITION |
| **TRANSITION** | 场景过渡中 | OUTDOOR, INDOOR |
| **LOADED** | 场景加载完成 | OUTDOOR, INDOOR |

### Interactions with Other Systems

| 系统 | 数据流向 | 接口 |
|------|---------|------|
| **玩家控制系统** ← | 玩家位置 → 触发器检测 | 玩家进入 Area2D 时触发 |
| **NPC 日程系统** ← | 当前场景 → NPC 加载 | 查询当前场景名 |
| **事件引擎** ← | 场景变更 → 事件触发 | 信号：`scene_changed(scene_name)` |
| **HUD 系统** ← | 当前场景 → 位置显示 | 查询接口：`get_current_scene()` |

## Formulas

无复杂公式。场景切换为状态机驱动。

## Edge Cases

- **如果在场景切换过程中按交互键**：忽略输入，等待切换完成
- **如果场景文件缺失**：显示错误提示，返回上一个有效场景
- **如果 NPC 在场景切换时正在对话**：暂停对话，场景加载后恢复
- **如果存档时正在场景切换中**：等待切换完成后再存档

## Dependencies

无上游依赖。被以下系统依赖：
- **NPC 日程系统**：依赖场景加载 NPC
- **事件引擎**：依赖场景切换触发事件
- **玩家控制系统**：依赖场景碰撞层
- **HUD 系统**：依赖场景名称显示

## Tuning Knobs

| 旋钮 | 默认值 | 范围 | 说明 |
|------|--------|------|------|
| transition_duration | 0.5s | 0.3–1.0 | 黑屏过渡时间 |
| scene_load_timeout | 5.0s | 3.0–10.0 | 场景加载超时时间 |

## Visual/Audio Requirements

- 场景过渡动画（黑屏渐变/开门效果）
- 室内场景的光影效果（窗户光线）
- 场景切换时的音效（开门声/脚步声）

## UI Requirements

- 场景切换时的 loading 提示（如果加载时间 > 1 秒）

## Acceptance Criteria

- GIVEN 角色在家门口，WHEN 走进触发器，THEN 播放过渡动画并加载室内场景
- GIVEN 角色在室内，WHEN 走到门口按交互键，THEN 返回室外场景
- GIVEN 场景切换中，WHEN 玩家按交互键，THEN 输入被忽略
- GIVEN 场景切换完成，WHEN 加载新场景，THEN NPC 位置正确恢复

## Open Questions

- 室内场景的进入/退出触发器布局需要关卡设计
