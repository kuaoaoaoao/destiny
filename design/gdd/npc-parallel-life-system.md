# NPC 平行人生系统

> **Status**: Designed
> **Author**: Claude + User
> **Last Updated**: 2026-06-15
> **Implements Pillar**: Pillar 5（多周目见全貌）— 见证伙伴的所有可能命运

## Overview

**NPC 平行人生系统**是游戏的功能层，负责管理 6 个童年伙伴的多版本人生线。它是情感连接的核心——玩家不只是「过自己的人生」，还亲眼见证伙伴们的命运。

**技术层面**：每个伙伴有多条人生线（平行命运），根据玩家的选择和随机因素，伙伴走上不同的人生道路。好感度系统影响伙伴与玩家的关系深度。

**玩家体验层面**：玩家在小镇中见证伙伴们的不同命运——小刚可能成为企业家，也可能成为工人；小芳可能幸福结婚，也可能孤独一生。每次人生，伙伴的命运都可能不同。

**核心设计原则**：伙伴命运应该「有因果但不完全可控」——玩家的选择会影响伙伴，但也有随机性。

## Player Fantasy

**「这些人的人生和我交织在一起。」**

玩家见证伙伴命运时，应该感到这些不是「NPC」，而是「人」——有自己的梦想、挣扎、选择和结局。玩家会影响他们，但不能完全控制他们。每次人生看到不同版本的伙伴，就是「多周目见全貌」的核心。

**支柱服务**：直接服务 Pillar 5（多周目见全貌）— 见证伙伴的所有可能命运。

## Detailed Design

### Core Rules

**1. 六个童年伙伴**

| 伙伴 | 出身 | 核心矛盾 | 多版本命运 |
|------|------|---------|-----------|
| 小刚 | 贫困家庭 | 「我拼尽全力，只能勉强活着」 | 企业家/工人/失业 |
| 小芳 | 农村普通 | 「我没有选择，只能被选择」 | 幸福婚姻/离婚/单身 |
| 大壮 | 城镇普通 | 「我想要更多，但不知道要什么」 | 小卖部老板/外出打工/继承家业 |
| 小美 | 城市中产 | 「我有自由，但社会想定义我」 | 职业女性/全职妈妈/独立创业 |
| 小明 | 富裕家庭 | 「我什么都有，但不知道要什么」 | 继承家业/自己创业/啃老 |
| 小红 | 贫困家庭 | 「我的人生从一开始就不属于我」 | 嫁人改变命运/自己奋斗/认命 |

**2. 人生线分支规则**
- 伙伴的人生线在玩家人生节点时分支
- 分支受玩家选择、好感度、随机因素影响
- 每次人生，伙伴可能走上不同道路

**3. 好感度系统**
- 好感度范围：0-100
- 通过对话、事件、选择影响
- 好感度影响伙伴的人生选择
- 高好感度：伙伴更可能做出「好」的选择
- 低好感度：伙伴更可能做出「差」的选择

### Interactions with Other Systems

| 系统 | 数据流向 | 接口 |
|------|---------|------|
| **NPC 日程系统** ← | 人生线 → NPC 日程版本 | 查询伙伴当前人生线 |
| **对话系统** ← | 好感度 → 对话分支 | 查询好感度值 |
| **命运系统** ← | 玩家选择 → 伙伴命运 | 信号：`life_choice_made` |
| **人生节点系统** ← | 节点选择 → 人生线分支 | 信号：`life_node_completed` |

## Formulas

好感度影响公式：
`affinity_effect = base_effect × relationship_multiplier`

| 变量 | 符号 | 类型 | 范围 | 描述 |
|------|------|------|------|------|
| base_effect | B | int | -10–10 | 基础好感度变化 |
| relationship_multiplier | R | float | 0.5–2.0 | 关系倍率 |

## Edge Cases

- **如果伙伴人生线冲突**：使用优先级更高的命运
- **如果好感度为 0**：伙伴不再与玩家互动
- **如果伙伴命运与玩家选择矛盾**：以伙伴命运为准

## Dependencies

依赖：
- **NPC 日程系统**：查询 NPC 位置
- **对话系统**：查询好感度
- **命运系统**：接收玩家选择
- **人生节点系统**：接收节点选择

被以下系统依赖：
- **存档系统**：需要序列化人生线状态
- **命运全景图**：需要显示所有可能命运

## Tuning Knobs

| 旋钮 | 默认值 | 范围 | 说明 |
|------|--------|------|------|
| affinity_decay_rate | 0.1 | 0.0–0.5 | 好感度衰减率（每天） |
| fate_random_weight | 0.3 | 0.0–0.5 | 随机因素权重 |

## Visual/Audio Requirements

- 伙伴不同人生线的外观变化
- 好感度变化的视觉反馈
- 伙伴命运揭晓的过场

## UI Requirements

- 好感度显示（伙伴头像旁）
- 伙伴人生线状态（命运之书中）

## Acceptance Criteria

- GIVEN 玩家帮助小刚，WHEN 好感度增加，THEN 小刚人生线偏向「好」的方向
- GIVEN 每次人生，WHEN 查看小刚命运，THEN 可能看到不同版本
- GIVEN 好感度为 0，WHEN 尝试与小刚对话，THEN 对话选项受限

## Open Questions

- 伙伴命运的具体分支数量需要设计
- 好感度对命运的影响程度需要平衡
