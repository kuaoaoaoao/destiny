# 命运系统

> **Status**: Designed
> **Author**: Claude + User
> **Last Updated**: 2026-06-15
> **Implements Pillar**: Pillar 2（没有好坏，只有不同）— 数值无好坏，只有不同

## Overview

**命运系统**是游戏的功能层，负责管理六大数值、命运之骰和命运之书。它是「选择有重量」的感知基础——玩家通过数值变化感受到选择的后果。

**技术层面**：管理六大数值（健康、心理、教育、金钱、社交、家庭），命运之骰（出生随机），命运之书（人生记录）。数值通过事件修改，通过 UI 展示。

**玩家体验层面**：玩家通过数值面板看到自己的人生状态——健康下降、心理波动、教育积累、金钱增减。数值不是「分数」，而是人生的「维度」。

**核心设计原则**：数值应该「被感受到，不被计算」——玩家感知到变化，但不需要精确计算。

## Player Fantasy

**「这就是我的人生。」**

玩家查看数值面板时，应该感到这些数字代表的是真实的人生维度——健康不只是 HP，是身体状况；心理不只是 MP，是精神状态；教育不只是 EXP，是知识积累。数值变化应该有情感重量。

**支柱服务**：直接服务 Pillar 2（没有好坏，只有不同）— 数值无好坏，只有不同的人生轨迹。

## Detailed Design

### Core Rules

**1. 六大数值**

| 数值 | 符号 | 范围 | 描述 |
|------|------|------|------|
| 健康 | HP | 0–100 | 身体状况 |
| 心理 | MP | 0–100 | 精神状态 |
| 教育 | ED | 0–100 | 知识积累 |
| 金钱 | MG | 0–100 | 经济状况 |
| 社交 | SC | 0–100 | 人际关系 |
| 家庭 | FM | 0–100 | 家庭关系 |

**2. 命运之骰**
- 出生时随机分配初始数值（基于出身背景）
- 不同出身有不同的数值分布
- 随机性 ±15% 浮动

**3. 数值修改规则**
- 事件结果直接修改数值
- 数值不能超过 0-100 范围
- 数值变化有视觉反馈（+/- 动画）

**4. 命运之书**
- 记录关键事件和数值变化
- 每次人生结束后生成命运之书
- 命运之书是多周目的「回忆录」

### Interactions with Other Systems

| 系统 | 数据流向 | 接口 |
|------|---------|------|
| **事件引擎** ← | 事件结果 → 数值修改 | 调用接口：`modify_stats(effects)` |
| **人生节点系统** ← | 人生节点 → 数值变化 | 调用接口：`apply_node_effects(effects)` |
| **数值面板 UI** ← | 数值状态 → UI 显示 | 查询接口：`get_stats()` |
| **命运之书 UI** ← | 人生记录 → 书显示 | 查询接口：`get_life_record()` |
| **存档系统** ← | 数值状态 → 存档 | 序列化接口 |

## Formulas

数值变化公式：
`new_stat = clamp(old_stat + change, 0, 100)`

| 变量 | 符号 | 类型 | 范围 | 描述 |
|------|------|------|------|------|
| old_stat | O | int | 0–100 | 原数值 |
| change | C | int | -50–50 | 变化量 |

**输出范围**：0–100
**示例**：健康 80 + (-10) = 70

## Edge Cases

- **如果数值变化超出范围**：限制在 0-100，不溢出
- **如果多个事件同时修改同一数值**：按执行顺序累加
- **如果数值降到 0**：触发特殊事件（如健康为 0 触发生病）
- **如果命运之骰结果不理想**：无特殊处理——这是命运

## Dependencies

依赖：
- **事件引擎**：接收数值修改
- **人生节点系统**：接收节点效果

被以下系统依赖：
- **NPC 平行人生系统**：依赖数值影响人生线
- **存档系统**：需要序列化数值
- **数值面板 UI**：需要显示数值
- **命运之书 UI**：需要显示记录

## Tuning Knobs

| 旋钮 | 默认值 | 范围 | 说明 |
|------|--------|------|------|
| stat_change_animation_duration | 0.5s | 0.3–1.0 | 数值变化动画时间 |
| dice_random_range | 15% | 10–20% | 命运之骰随机浮动范围 |

## Visual/Audio Requirements

- 数值变化的 +/- 动画
- 命运之骰的掷骰动画
- 命运之书的翻页效果

## UI Requirements

- 数值面板 UI（六大数值显示）
- 命运之书 UI（人生记录）

## Acceptance Criteria

- GIVEN 事件修改健康 -10，WHEN 健康为 80，THEN 健康变为 70
- GIVEN 命运之骰掷出，WHEN 出身为农村普通，THEN 初始数值在合理范围内
- GIVEN 数值变化，WHEN 查看数值面板，THEN 显示 +/- 动画
- GIVEN 人生结束，WHEN 查看命运之书，THEN 显示完整人生记录
