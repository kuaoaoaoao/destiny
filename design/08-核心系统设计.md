# 08 - 核心系统设计

---

## 一、数值系统

### 1.1 六大核心数值

| 数值 | 含义 | 范围 | 说明 |
|------|------|------|------|
| 💰 金钱 | 经济状况 | 0-100 | 包括收入、存款、资产 |
| 🧠 心理 | 心理健康 | 0-100 | 包括情绪、抗压能力、幸福感 |
| 💪 健康 | 身体状况 | 0-100 | 包括体质、疾病、精力 |
| 👥 社交 | 人际关系 | 0-100 | 包括朋友、人脉、社会支持 |
| 📚 教育 | 学历/知识 | 0-100 | 包括学历、技能、视野 |
| 😊 幸福 | 综合幸福感 | 0-100 | 综合指标 |

### 1.2 数值之间的关系

**基本关系：**
```
幸福 = f(金钱, 心理, 健康, 社交, 教育)
```

**具体关系：**

| 关系 | 说明 |
|------|------|
| 金钱↑ → 心理↑ | 但有上限，超过阈值后影响减弱 |
| 健康↓ → 心理↓ | 身体不好，心情也不好 |
| 社交↑ → 心理↑ | 有人支持，心理更健康 |
| 教育↑ → 金钱↑ | 但不是线性关系 |
| 金钱↑ + 健康↓ → 幸福↓ | 有钱没命花 |
| 心理↓ → 健康↓ | 心理问题会影响身体 |
| 社交↓ → 心理↓ | 孤独会导致心理问题 |

### 1.3 数值阈值

| 数值 | 低阈值 | 中阈值 | 高阈值 | 说明 |
|------|--------|--------|--------|------|
| 金钱 | <20 | 20-60 | >60 | 低于20为贫困 |
| 心理 | <30 | 30-60 | >60 | 低于30可能抑郁 |
| 健康 | <30 | 30-60 | >60 | 低于30为亚健康 |
| 社交 | <20 | 20-60 | >60 | 低于20为孤独 |
| 教育 | <20 | 20-60 | >60 | 低于20为低学历 |
| 幸福 | <30 | 30-60 | >60 | 低于30为不幸福 |

### 1.4 数值变化规则

**自然变化：**
- 健康：每年-1（年龄损耗）
- 心理：根据事件变化
- 金钱：根据收入和支出变化
- 社交：根据事件变化
- 教育：根据学习和经历变化

**事件影响：**
- 每个事件都会影响一个或多个数值
- 影响大小取决于事件的严重程度
- 有些事件有长期影响（如：慢性病持续影响健康）

**连锁反应：**
- 一个数值的变化可能触发其他数值的变化
- 例如：失业（金钱↓）→ 焦虑（心理↓）→ 失眠（健康↓）

## 二、事件系统

### 2.1 事件分类

| 类型 | 说明 | 示例 |
|------|------|------|
| 必然事件 | 每个人都会遇到 | 毕业、工作、变老 |
| 概率事件 | 根据条件概率发生 | 裁员、生病、中奖 |
| 选择事件 | 玩家可以做出选择 | 考研vs就业、一线城市vs回老家 |
| 连锁事件 | 一个事件触发另一个事件 | 失业→焦虑→失眠 |
| 隐藏事件 | 需要特定条件才会触发 | 中年危机、人生转折 |

### 2.2 事件触发条件

**条件类型：**

| 条件类型 | 说明 | 示例 |
|---------|------|------|
| 数值条件 | 数值达到某个阈值 | 金钱<20 触发"贫困事件" |
| 时间条件 | 到达某个年龄 | 35岁触发"中年危机" |
| 概率条件 | 随机概率 | 10%概率触发"被裁员" |
| 组合条件 | 多个条件同时满足 | 年龄>35 + 互联网行业 触发"35岁危机" |
| 前置事件 | 某个事件发生后 | "结婚"后可能触发"离婚" |

### 2.3 事件影响

**影响类型：**

| 影响类型 | 说明 | 示例 |
|---------|------|------|
| 即时影响 | 立即改变数值 | "被裁员" → 金钱-30 |
| 持续影响 | 持续改变数值 | "慢性病" → 每年健康-5 |
| 条件影响 | 满足条件后改变 | "买房" → 有房后安全感+10 |
| 解锁影响 | 解锁新的事件/选择 | "考上大学" → 解锁"考研"选项 |

## 三、命运全景图系统

### 3.1 系统说明

命运全景图是游戏的核心系统之一，它展示了玩家人生中所有可能的分支。

**功能：**
- 显示当前人生的所有选择点
- 每个选择点显示所有可能的选项
- 每个选项显示可能的结果
- 玩家可以查看"如果当时选了另一条路"

### 3.2 选择点设计

**选择点类型：**

| 类型 | 说明 | 示例 |
|------|------|------|
| 重大选择 | 影响人生走向 | 高考志愿、结婚对象、职业选择 |
| 中等选择 | 影响部分人生 | 跳槽、搬家、生孩子 |
| 小选择 | 影响细节 | 买什么东西、去哪里玩 |

**选择点展示：**

```
┌─────────────────────────────────────────┐
│            选择点：高考志愿              │
│                                         │
│  当前选择：二本，计算机专业              │
│                                         │
│  其他可能：                              │
│  ├── 一本，金融专业                      │
│  ├── 二本，医学专业                      │
│  ├── 专科，技术专业                      │
│  ├── 复读                               │
│  └── 直接打工                            │
│                                         │
│  [查看每个选项的可能结果]                │
└─────────────────────────────────────────┘
```

### 3.3 分支可视化

**分支展示方式：**

```
                    ┌── 大厂程序员 ── 高薪 ── 35岁危机 ── ...
                    │
        ┌── 计算机 ─┼── 中厂程序员 ── 稳定 ── ...
        │           │
        │           └── 小厂程序员 ── 普通 ── ...
        │
二本 ───┤
        │           ┌── 医生 ── 稳定但周期长 ── ...
        │           │
        └── 医学 ──┼── 护士 ── 稳定 ── ...
                    │
                    └── 药企 ── ...
```

## 四、命运之书系统

### 4.1 系统说明

命运之书是记录玩家每次人生经历的系统。

**功能：**
- 记录每次人生的关键信息
- 显示人生总结
- 允许回看和对比

### 4.2 命运之书内容

**基本信息：**
- 出生设定（家庭、性别、地区）
- 学历
- 职业
- 婚姻状况
- 孩子情况
- 住房情况

**关键事件：**
- 童年关键事件
- 少年关键事件
- 青年关键事件
- 中年关键事件
- 老年关键事件

**数值轨迹：**
- 各数值随时间的变化曲线
- 关键转折点

**人生评价：**
- 幸福指数
- 人生评价（一句话）

### 4.3 命运之书展示


## 五、全知模式系统

### 5.1 解锁条件

- 体验了足够多的人生（建议20次以上）
- 覆盖了不同背景、不同性别、不同选择

### 5.2 全知模式内容

**在全知模式中：**
- 玩家可以看到所有可能的人生轨迹
- 每个选择的所有后果都可见
- 没有随机性，只有选择
- 玩家需要做出一个"最终选择"

### 5.3 最终选择

**最终问题：**

> "你已经看遍了所有的人生。"
> "现在，如果这就是你的人生——"
> "你想怎么过？"

**选择维度：**

| 维度 | 选项 |
|------|------|
| 家庭背景 | 选择一个起点 |
| 性别 | 男/女 |
| 学历目标 | 高中/专科/二本/一本/985 |
| 职业方向 | 稳定/高薪/自由/创业 |
| 城市选择 | 一线/二线/老家 |
| 婚姻选择 | 结婚/不结婚/晚婚 |
| 生育选择 | 生/不生/生几个 |
| 生活态度 | 拼搏/平淡/躺平 |

## 六、存档系统

### 6.1 存档内容

- 当前人生阶段
- 所有数值
- 所有已触发事件
- 所有选择记录
- 命运之书历史

### 6.2 存档方式

- 自动存档：每个阶段结束时自动存档
- 手动存档：玩家可以随时存档
- 多存档位：支持多个存档

## 七、成就系统

### 7.1 成就类型

| 类型 | 说明 | 示例 |
|------|------|------|
| 人生成就 | 完成特定人生 | "平凡一生"、"逆袭成功" |
| 选择成就 | 做出特定选择 | "不婚主义者"、"丁克家庭" |
| 事件成就 | 触发特定事件 | "中年危机"、"被裁员" |
| 数值成就 | 数值达到特定值 | "财富自由"、"心理健康" |
| 探索成就 | 体验不同人生 | "体验了10种人生"、"覆盖所有背景" |

### 7.2 成就展示

**成就名称：** 平凡之路
**成就描述：** 完成一次普通的人生
**达成条件：** 从出生到死亡，没有重大变故

**成就名称：** 逆袭
**成就描述：** 从贫困家庭走向富裕
**达成条件：** 出生在贫困家庭，最终金钱>70

**成就名称：** 全知者
**成就描述：** 体验了所有可能的人生
**达成条件：** 体验20次以上不同人生
