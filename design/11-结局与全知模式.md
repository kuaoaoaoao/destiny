# 11 - 结局与全知模式

---

## 一、结局设计理念

### 核心原则

**没有"好结局"和"坏结局"，只有"不同的结局"。**

- 平凡一生不是坏结局
- 富贵一生不是好结局
- 每种人生都有它的价值和遗憾

### 结局评价

**每个结局都会有一个"人生评价"，但这个评价不是判断好坏，而是描述状态：**

- "平凡但完整"
- "艰难但坚韧"
- "自由但孤独"
- "富裕但空虚"
- "平淡但幸福"
- "坎坷但精彩"

---

## 二、结局类型

### 结局1：平凡一生

**特征：**
- 普通工作、普通家庭、普通生活
- 没有大起大落
- 平淡但完整

**典型路径：**
```
普通家庭 → 二本 → 普通工作 → 结婚生子 → 还房贷 → 孩子上学 → 退休 → 平淡晚年
```

**人生评价：** "平凡但完整"
**幸福指数：** 55-65

---

### 结局2：孤独终老

**特征：**
- 没有伴侣、没有孩子
- 一个人
- 可能有遗憾

**典型路径：**
```
各种背景 → 不婚/离异 → 一个人生活 → 老年孤独
```

**人生评价：** "自由但孤独"
**幸福指数：** 40-55

---

### 结局3：儿孙满堂

**特征：**
- 孩子孝顺、家庭和睦
- 孙子绕膝
- 幸福

**典型路径：**
```
普通家庭 → 结婚生子 → 孩子孝顺 → 孙子出生 → 幸福晚年
```

**人生评价：** "平凡但幸福"
**幸福指数：** 65-75

---

### 结局4：中年崩塌

**特征：**
- 被裁员、离婚、负债
- 人生跌入谷底
- 可能爬起来，也可能爬不起来

**典型路径：**
```
普通家庭 → 工作 → 被裁员 → 离婚 → 负债 → 艰难生活
```

**人生评价：** "坎坷但坚韧"
**幸福指数：** 30-45

---

### 结局5：安享晚年

**特征：**
- 有存款、有退休金、有健康
- 孩子孝顺
- 生活舒适

**典型路径：**
```
中产家庭 → 稳定工作 → 存款充足 → 退休金高 → 舒适晚年
```

**人生评价：** "安稳但平淡"
**幸福指数：** 65-75

---

### 结局6：凄凉晚景

**特征：**
- 没钱、没人管
- 孤独离世
- 凄凉

**典型路径：**
```
贫困家庭 → 努力但不够 → 存款不足 → 无退休金 → 孩子不孝 → 凄凉晚年
```

**人生评价：** "艰难但坚韧"
**幸福指数：** 25-35

---

### 结局7：意外终结

**特征：**
- 疾病/事故
- 人生突然结束
- 来不及告别

**典型路径：**
```
各种背景 → 正常生活 → 突发疾病/意外 → 离世
```

**人生评价：** "短暂但完整"
**幸福指数：** 40-60（取决于之前的生活）

---

### 结局8：逆袭成功

**特征：**
- 从底层爬到中产/富裕
- 改变了命运
- 但付出了巨大代价

**典型路径：**
```
贫困家庭 → 努力学习 → 好大学 → 好工作 → 高薪 → 财务自由
```

**人生评价：** "艰难但精彩"
**幸福指数：** 55-70（付出了很多代价）

---

### 结局9：持续挣扎

**特征：**
- 一辈子都在和命运搏斗
- 没有放弃
- 但也没有赢

**典型路径：**
```
贫困家庭 → 努力 → 遇到困难 → 继续努力 → 又遇到困难 → 继续...
```

**人生评价：** "艰难但坚韧"
**幸福指数：** 35-50

---

### 结局10：接受平凡

**特征：**
- 理解了命运
- 平静地活着
- 不再焦虑

**典型路径：**
```
各种背景 → 经历起伏 → 理解人生 → 接受平凡 → 平静生活
```

**人生评价：** "平静但充实"
**幸福指数：** 60-70

---

## 三、结局触发条件

### 结局触发逻辑

**结局 = 最终状态的组合**

**最终状态包括：**
- 金钱水平
- 心理状态
- 健康状况
- 社交关系
- 家庭状态
- 人生经历

### 结局判断表

| 结局 | 金钱 | 心理 | 健康 | 社交 | 家庭 | 特殊条件 |
|------|------|------|------|------|------|---------|
| 平凡一生 | 30-60 | 40-60 | 40-60 | 30-60 | 有家庭 | 无重大变故 |
| 孤独终老 | 任意 | <50 | 任意 | <30 | 无伴侣/孩子 | 年龄>60 |
| 儿孙满堂 | 任意 | >60 | 任意 | >50 | 有孩子且孝顺 | 孙子出生 |
| 中年崩塌 | <20 | <30 | 任意 | <30 | 离婚 | 被裁员+负债 |
| 安享晚年 | >60 | >50 | >50 | >40 | 有家庭 | 退休金>4000 |
| 凄凉晚景 | <20 | <30 | <30 | <20 | 无支持 | 年龄>60 |
| 意外终结 | 任意 | 任意 | 任意 | 任意 | 任意 | 突发疾病/事故 |
| 逆袭成功 | >70 | >50 | >50 | >40 | 任意 | 出生贫困 |
| 持续挣扎 | <30 | <40 | <40 | <30 | 任意 | 多次重大挫折 |
| 接受平凡 | 任意 | >60 | 任意 | >40 | 任意 | 心态转变 |

## 四、命运之书

### 4.1 命运之书内容

**基本信息：**
- 出生设定（家庭、性别、地区）
- 学历
- 职业
- 婚姻状况
- 孩子情况
- 住房情况

**关键事件：**
- 童年关键事件
- 少年关键事件
- 青年关键事件
- 中年关键事件
- 老年关键事件

**数值轨迹：**
- 各数值随时间的变化曲线
- 关键转折点

**人生评价：**
- 幸福指数
- 人生评价（一句话）

## 五、全知模式

### 5.1 解锁条件

**解锁条件：**
- 体验了足够多的人生（建议20次以上）
- 覆盖了不同背景、不同性别、不同选择

**解锁提示：**
> "你已经看遍了所有的人生。"
> "现在，你可以进入全知模式了。"
> "在这里，你可以看到所有可能的人生。"
> "然后，做出你的选择。"

### 5.2 全知模式内容

**在全知模式中：**
- 玩家可以看到所有可能的人生轨迹
- 每个选择的所有后果都可见
- 没有随机性，只有选择
- 玩家需要做出一个"最终选择"

### 5.4 最终选择

**最终问题：**

> "你已经看遍了所有的人生。"
> "有人生在富裕家庭却一生空虚。"
> "有人生在贫困家庭却活得充实。"
> "有人努力一辈子还是普通人。"
> "有人不努力却衣食无忧。"
> "有人选择了事业却失去了家庭。"
> "有人选择了家庭却失去了自己。"
> 
> "现在，如果这就是你的人生——"
> "你想怎么过？"

**选择维度：**

| 维度 | 选项 | 说明 |
|------|------|------|
| 人生目标 | 成功/平凡/自由 | 你想要什么样的人生 |
| 职业选择 | 高薪/稳定/兴趣 | 你想要什么样的工作 |
| 城市选择 | 一线/二线/老家 | 你想要住在哪里 |
| 婚姻选择 | 结婚/不婚/顺其自然 | 你想要什么样的感情生活 |
| 生活态度 | 拼搏/平淡/躺平 | 你想要什么样的生活节奏 |

## 六、成就系统

### 6.1 人生成就

| 成就名 | 描述 | 达成条件 |
|--------|------|---------|
| 平凡之路 | 完成一次普通的人生 | 从出生到死亡，无重大变故 |
| 逆袭 | 从贫困走向富裕 | 出生贫困，最终金钱>70 |
| 孤独终老 | 一个人走完一生 | 无伴侣，年龄>70 |
| 儿孙满堂 | 享受天伦之乐 | 有孩子且孝顺，孙子出生 |
| 中年危机 | 经历中年危机 | 年龄35-50，心理<40 |
| 安享晚年 | 享受舒适的晚年 | 年龄>60，金钱>60，健康>50 |
| 凄凉晚景 | 经历凄凉的晚年 | 年龄>60，金钱<20，社交<20 |
| 坚韧不屈 | 经历多次挫折但没有放弃 | 经历3次以上重大挫折 |
| 心态平和 | 接受了平凡 | 心理>60，幸福>60 |
| 财务自由 | 实现了财务自由 | 金钱>80 |
| 健康长寿 | 活到80岁以上 | 年龄>80 |
| 教育改变命运 | 通过教育改变命运 | 出生教育<20，最终教育>60 |

### 6.2 探索成就

| 成就名 | 描述 | 达成条件 |
|--------|------|---------|
| 初次体验 | 完成第一次人生 | 完成1次人生 |
