---

## ⚠️ 生成前的关键提醒（必读）

**地砖和物件的生成逻辑完全不同，务必区分：**

| 类型 | 视角 | 背景 | 拼接要求 |
|------|------|------|---------|
| **地砖** | 纯俯视（正上方往下看） | 纯色或透明 | **必须无缝拼接**（最难） |
| **物件** | 俯视斜 45°（2.5D） | **透明背景** | 不需要拼接 |

> 💡 **关键**：地砖是"纯俯视"（像航拍往下看），物件是"斜 45°"（像侧后方看）。两者视角不同但能配合——这就是星露谷的效果。

> 地砖是最难生成的，**生成后必须在 PS/Aseprite 里检查能否无缝拼接**，不能则手动修边缘。

## 【地砖-1】草地（最重要，先做这个）

**用途**：院子、田野、小镇大部分地面。

### 完整提示词（中文）

```
扁平手绘插画，暖色调，柔和平涂上色，没有描边,

```

### 完整提示词（英文）

```
flat hand-drawn illustration, warm color palette, soft cel shading without outline,
square seamless texture pattern, a patch of green grass, even grass texture with subtle variations of green shades and small grass tufts,
strictly top-down view (looking straight down), seamlessly tileable texture,
no other elements, pure pattern, square composition, 48x48 pixel concept

**参数与技巧：**
- 比例：**1:1 正方形**
- **生成多张挑选**：AI 平铺纹理不一定好，多生几张挑能拼接的
- **验证拼接**：生成后在 PS 里复制成 2×2 排列，看接缝是否明显
- **建议生成 3-4 个变体**（深草/浅草/有野花/有草丛），拼图时混用更自然

# 🌳 第二组：户外物件

> 物件相对好生成。**关键是透视统一（俯视斜45°）+ 透明背景 + 底部接地阴影。**

**用途**：贯穿全游戏的情感符号，伙伴聚集地。

### 完整提示词（中文）

```

```

### 完整提示词（英文）

```
flat hand-drawn illustration, warm color palette, soft cel shading without outline,
storybook art style, Chinese countryside,
2.5D isometric perspective, a giant old pagoda tree, thick twisted trunk, lush canopy blocking the sky,

**参数与技巧：**

# ✅ 验收标准

## 地砖验收（最严格）

- [ ] **正方形**（1:1）
- [ ] **纯俯视视角**（不是斜视）
- [ ] **可无缝拼接**：复制成 2×2 排列，接缝不明显
- [ ] **暖色调统一**：所有地砖色温一致
- [ ] **无描边、平涂**

> ⚠️ 地砖拼接不上的话，**必须在 PS 里手动修边缘**，这是绕不开的步骤。

## 物件验收

- [ ] **俯视斜 45° 透视**统一
- [ ] **透明背景**（PNG 带 alpha）
- [ ] **底部有接地阴影**
- [ ] **风格统一**（和地砖、和其他物件视觉一致）
- [ ] **无描边、平涂、暖色调**

## 整体一致性

- [ ] 地砖（纯俯视）+ 物件（斜 45°）放一起**协调**，不违和
- [ ] 所有素材暖色调一致
- [ ] 放上角色 sprite 后**不违和**

# ⚠️ 常见问题与修正

| 问题 | 解决 |
|------|------|
| 地砖拼接有明显接缝 | PS 里用"仿制图章"修边缘，让左右、上下像素连续 |
| AI 生成的地砖有透视感（不像航拍） | 强化"严格纯俯视、正上方往下看、无透视" |
| 物件背景不是透明的 | 用 removebg.com 或 PS 抠图 |
| 物件没有接地阴影 | 强化"底部必须有柔和的椭圆接地阴影"，或 PS 手动加 |
| 物件透视和地砖不搭 | 地砖纯俯视 + 物件斜 45° 是正确的，参考星露谷就是如此 |
| 家具风格和建筑不统一 | 用同一风格锚 + 同一参考图垫图 |
| AI 在黑板/招牌写错字 | 让 AI 留白或写英文，PS 手动加中文 |

# 💡 省时省力建议

1. **地砖考虑买现成**：itch.io 有大量 cheap 扁平风 tileset（搜 "flat illustration tileset"），几美元一套，比自己修边缘快。可以买来直接用或改色。

2. **物件用 AI 生成**：物件不需要拼接，AI 生成质量高，是 AI 的强项。

3. **装饰物件批量做**：灌木/石头/野花这类，一次生成一组（让 AI 出"一组乡村装饰物件的集合图"），PS 切开。

4. **保留所有 seed 和提示词**：风格统一的命脉。
