# 15 - NPC 伙伴与多线故事设计

> ⭐ 本文档定义"小镇 = 命运剧场"的核心：NPC 伙伴拥有平行于玩家的完整人生线，玩家在不同周目中见证他们的不同命运。这是游戏从星露谷式小镇生活上升到"命运全景"的关键系统。

---

## 一、设计理念

### 1.1 为什么 NPC 是灵魂

《命》的核心命题是"看遍所有的人生"。如果只有玩家自己的人生，再多周目也只是"换自己的出身"。

**真正的"看遍所有人"，是看到身边人不同的人生走向。** 你童年一起抓鱼的发小，这一周目是包工头，下一周目可能进了局子，再下一周目可能英年早逝。**这些伙伴的命运，才是命运全景图最有冲击力的内容。**

### 1.2 NPC 在游戏中的三层作用

| 层 | 作用 | 例子 |
|----|------|------|
| **生活层** | 让小镇有"人味"，不空洞 | 日常对话、闲聊、共同活动 |
| **叙事层** | 承载中国社会众生相 | 每个伙伴代表一种典型命运 |
| **命运层** | 多周目差异化的核心素材 | 同一伙伴不同周目不同人生，供全景图回看 |

### 1.3 NPC 设计原则

- ✅ **数量克制**：核心伙伴 6 个 + 长辈 4 个，不贪多
- ✅ **每个有辨识度**：性格、外貌、口头禅、标志性动作
- ✅ **每个人都有遗憾和获得**：不脸谱化，不简单好坏
- ✅ **MVP 先写死，后期再数值驱动**：见第十二节

## 二、童年伙伴群（核心，6 人）

### 2.1 伙伴一览

| 代号 | 性别 | 设定关键词 | 代表的群体 |
|------|------|----------|-----------|
| **小刚** | 男 | 调皮、讲义气、不爱学习 | 早早打工的农村男孩 |
| **小芳** | 女 | 乖巧、青梅竹马、漂亮 | 因婚姻改变命运的女孩 |
| **阿强** | 男 | 老实、能吃苦、家中长子 | 当兵/跑运输的农村男孩 |
| **丽丽** | 女 | 学习好、家境好、有想法 | 考出去的女大学生 |
| **大壮** | 男 | 家里开小卖部、嘴甜、市侩 | 守业或经商的小镇青年 |
| **小梅** | 女 | 留守儿童、沉默、早熟 | 早婚或外出打工的留守女孩 |

> 设计意图：6 人覆盖了乡村/小镇最常见的 6 种典型人生轨迹，男女各 3，有学习好的有学习差的，有富的有穷的，有走出去的有留下的。**每个人代表一类真实的人。**

### 2.2 伙伴的"出场"与"成长"

每个伙伴从童年到老年都有完整形象演变：

| 伙伴 | 童年形象 | 少年演变 | 成年样貌 |
|------|---------|---------|---------|
| 小刚 | 鼻涕虫、跑得快 | 个子窜、染头发/留长发 | 可能晒黑壮实 / 可能文身消瘦 |
| 小芳 | 扎马尾、笑起来有酒窝 | 长高、变漂亮 | 打扮精致 / 或憔悴朴素 |
| 阿强 | 黑、结实 | 一直壮实 | 军人板寸 / 司机晒得黝黑 |
| 丽丽 | 戴眼镜、抱书 | 越来越书卷气 | 戴眼镜、文气 / 或国外回来 |
| 大壮 | 胖、嘴馋 | 依然胖、开始算账 | 发福、穿夹克 / 或精明瘦削 |
| 小梅 | 瘦小、不说话 | 依然瘦小、眼神躲闪 | 憔悴 / 或温柔但疲惫 |

## 三、伙伴的多版本人生线（核心机制）

### 3.1 机制说明

**每个伙伴有 3-5 个"预设人生版本"。每周目开始时，根据某种规则（出身/随机种子）为每个伙伴选定一个版本。** 玩家在该周目中只能见证伙伴的这一个版本，要看其他版本得换周目。

```
伙伴：小刚
├── 版本A：南下打工仔 → 工厂上班 → 娶同乡 → 回乡开小店
├── 版本B：跟着社会青年混 → 进局子 → 出来后无所事事
├── 版本C：去学手艺 → 木匠/水电工 → 娶妻生子，平凡但踏实
├── 版本D：意外（车祸/溺水）→ 英年早逝
└── 版本E：被部队招走 → 当兵 → 退伍转业 → 安稳
```

### 3.2 伙伴小刚 —— 5 个版本人生详解

**作为设计模板，详细展开小刚的全部 5 个版本：**

#### 版本A：南下打工仔（基础版，最常见）

| 年龄 | 事件 | 玩家如何知晓 |
|------|------|------------|
| 7 | 和你一起抓鱼、被老师罚站 | 直接相遇（学校） |
| 12 | 初中开始厌学，和你渐行渐远 | 直接相遇（学校） |
| 15 | 中考落榜，决定跟亲戚南下 | **告别场景**（车站，重要泪点） |
| 18 | 你高考那年收到他的信：在广东工厂 | 书信 |
| 22 | 过年回来，黑了瘦了，给你带礼物 | 回乡相遇 |
| 25 | 娶了同厂女孩，过年办酒 | 听说 + 可选参加婚礼 |
| 28 | 攒了点钱，回镇上开了个小五金店 | 小镇相遇（店已开） |
| 35 | 生意还行，孩子上学 | 偶尔遇见 |
| 45 | 孩子考上高中，他满足 | 闲聊 |
| 60 | 退休，每天在老槐树下下棋 | 镇上偶遇 |

**情感关键词：** 务实、坚韧、平凡的幸福

#### 版本B：误入歧途

| 年龄 | 事件 | 玩家如何知晓 |
|------|------|------------|
| 7-12 | 同版本A | 同 |
| 15 | 辍学，开始和镇上"混混"混在一起 | 直接相遇（外貌变化） |
| 17 | **关键选择**：小刚拉你一起"搞点钱"，你拒绝/参与 | 玩家选择（影响玩家命运） |
| 18 | 你高考时，小刚因盗窃被抓 | 听说（长辈转述） |
| 22 | 你大学毕业，小刚刚出来，瘦得脱相 | 偶遇（镇口） |
| 25 | 又进去了 | 听说 |
| 30 | 出来后没人理，借酒浇愁 | 偶遇（醉倒在桥边） |
| 40 | 失踪，可能客死他乡 | 长辈叹息 |

**情感关键词：** 警示、惋惜、命运的岔路

#### 版本C：手艺人

| 年龄 | 事件 | 玩家如何知晓 |
|------|------|------------|
| 7-12 | 同A | 同 |
| 15 | 中考落榜，去县城学木匠 | 告别 |
| 20 | 出师，开始接活 | 听说 |
| 25 | 手艺出名，娶了隔壁村姑娘 | 婚礼 |
| 30-60 | 一直在镇上做木匠，踏实本分 | 长期存在 |

**情感关键词：** 踏实、安稳、另一种成功

#### 版本D：英年早逝

| 年龄 | 事件 | 玩家如何知晓 |
|------|------|------------|
| 7-15 | 同A | 同 |
| 17 | **夏天游泳溺水** / 或车祸 | 长辈沉重告知，全镇震动 |
| 18+ | 小刚家的窗户再没亮过 | 场景细节（他家空了） |
| 老年 | 路过河边，触发回忆 CG | 回忆 |

**情感关键词：** 突然、遗憾、生命无常

#### 版本E：当兵转业

| 年龄 | 事件 | 玩家如何知晓 |
|------|------|------------|
| 7-15 | 同A | 同 |
| 16 | 部队征兵，小刚去了 | 告别 |
| 18-30 | 部队生活，偶有书信 | 书信 |
| 32 | 退伍，转业到县城单位 | 听说 + 偶遇 |
| 40+ | 稳定，是镇上"有出息"的代表 | 镇上口碑 |

**情感关键词：** 出息、另一种出路

### 3.3 其余 5 个伙伴的版本概要

> 详细版（像小刚那样逐年龄展开）留待开发期补充，这里先定方向。

#### 小芳 —— 青梅竹马（4 版本）

| 版本 | 走向 | 情感 |
|------|------|------|
| A | 嫁到邻县，平凡主妇 | 平淡 |
| B | 你和她错过（你没表白），她远嫁他乡，多年后重逢 | 遗憾 |
| C | 考上师范，回镇当老师，独立未婚 | 独立 |
| D | 嫁错人，家暴/离婚回乡，你中年时重逢 | 心疼 |

> **小芳的特殊性**：她是潜在的恋爱线。如果玩家选择追求，可能触发"版本B"的另一种结局（你们在一起）。这是 6 伙伴中唯一可恋爱的。

#### 阿强 —— 发小（4 版本）

| 版本 | 走向 |
|------|------|
| A | 当兵 → 退伍转业 |
| B | 跑长途货运 → 辛苦但赚钱 |
| C | 继承父亲种地/养殖 → 守着老家 |
| D | 工地意外受伤 → 落下残疾 |

#### 丽丽 —— 学霸女同学（3 版本）

| 版本 | 走向 |
|------|------|
| A | 考上 985 → 出国 → 海归精英 |
| B | 考上师范 → 回县城当老师 |
| C | 大学遭遇变故（家里出事/抑郁）→ 辍学回乡 |

#### 大壮 —— 小卖部家的（3 版本）

| 版本 | 走向 |
|------|------|
| A | 守着小卖部一辈子，平淡 |
| B | 进城做生意，失败负债回乡 |
| C | 镇上拆迁/土地增值，意外暴富 |

#### 小梅 —— 留守儿童（4 版本）

| 版本 | 走向 |
|------|------|
| A | 初中没毕业就外出打工 |
| B | 早婚，嫁到外省 |
| C | 考上师范，像丽丽一样走出去 |
| D | 打工时失踪/被骗，再无音讯 |

### 3.4 版本选择规则（MVP：写死）

**MVP 阶段，伙伴版本选择规则简单粗暴：**

```
每周目开始时：
1. 根据玩家出身，固定部分伙伴的版本（如：玩家贫困 → 小梅触发版本A打工）
2. 其余伙伴版本完全随机抽取（1-X 之间）
3. 用"周目种子"确保同一周目内伙伴版本不变
```

**后期（数值驱动版）会改为：** 伙伴也跑简化版六大数值，根据数值演变动态决定走向。但 MVP 不做。

### 3.5 版本与命运全景图的关系

**伙伴的多版本人生，是命运全景图的核心展示内容：**

- 玩家在某周目见证小刚的版本A
- 进入命运全景图，点小刚的节点
- 看到："这一周目小刚走了打工路。但他还可能有这些命运..." → 展示版本 B/C/D/E 的概要
- 已见证的版本亮起，未见证的版本灰显，激励玩家换周目探索

**这就是"看遍所有人的人生"。**

## 四、长辈 NPC（4 人，辅助）

### 4.1 长辈一览

| 代号 | 身份 | 作用 |
|------|------|------|
| **妈妈** | 主角母亲 | 全程核心，家庭线主轴 |
| **爸爸** | 主角父亲 | 全程，可能是缺席的（外出打工） |
| **王老师** | 小学班主任 | 童年少年引路人，可能影响教育 |
| **张大爷** | 镇上老人/村口老者 | "命运旁观者"，提供旁白式哲理 |

### 4.2 长辈的人生线

长辈也有自己的命运，但**不是随机的**，更多由玩家出身和家庭背景决定：

| 长辈 | 命运变体 |
|------|---------|
| 妈妈 | 健康长寿 / 中年患病 / 过劳早逝（取决于家境和玩家选择） |
| 爸爸 | 在家 / 外出打工偶尔回 / 出事故 / 离家出走 |
| 王老师 | 调走 / 升校长 / 留下坚守 / 因病退休 |
| 张大爷 | 一直在 → 某年去世（象征时间流逝） |

> **张大爷的特殊设计：** 他是游戏的"旁白化身"。年轻时他在村口摆棋摊，老年时他还在，但越来越少出现，最终某天他的棋摊空了——玩家意识到他走了，这是重要的"时间感"教育。

## 五、玩家如何"遇到"伙伴的命运

### 5.1 五种遇到方式

| 方式 | 说明 | 沉浸度 | 实现难度 |
|------|------|--------|---------|
| **直接相遇** | 在小镇撞见，外观/状态变化 | ⭐⭐⭐⭐⭐ | 中 |
| **听说** | 长辈/NPC 嘴里转述"你听说没..." | ⭐⭐⭐⭐ | 低 |
| **书信/消息** | 收到伙伴的信/朋友圈 | ⭐⭐⭐⭐ | 低 |
| **缺席暗示** | 该出现的地方没人了（暗示去世/离开） | ⭐⭐⭐⭐⭐ | 中 |
| **回忆 CG** | 老年路过老地方，触发闪回 | ⭐⭐⭐⭐⭐ | 高（需 CG） |

### 5.2 遇到方式的情感层次设计

**同一个事件（如"小刚去打工"），用不同方式遇到，情感强度不同：**

- 直接相遇告别（车站）→ 最强，玩家在场
- 听说（"小刚走了，昨天走的"）→ 次强，事后知晓的怅然
- 缺席暗示（去小刚家发现锁着门）→ 留白，淡淡的失落

**设计时要混用**，避免每个事件都是"直接撞见"，那样会腻。

### 5.3 缺席暗示（高级技巧）

**这是最具沉浸感的手法，也是星露谷等游戏不常做的：**

- 你 12 岁暑假回镇，发现小梅家的门常年锁着（暗示她已外出）
- 你 35 岁回乡，发现小刚家的五金店挂着"转让"
- 你 60 岁散步，发现老槐树下的棋摊空了（张大爷走了）
- 你 70 岁，镇上熟悉的面孔越来越少

**"不在"比"在场"更有冲击力。** 这是叙事游戏的高级技巧，必须用好。

## 六、好感度系统

### 6.1 设计原则：轻量

**不做星露谷那种"送礼刷满"的重系统。** 好感度只是"关系的简单记录"，关键靠事件选择。

### 6.2 好感度机制

| 元素 | 设计 |
|------|------|
| 数值范围 | 0-100，分 5 档（陌生/认识/朋友/挚友/知己） |
| 提升 | **关键选择**（如小刚被欺负时帮不帮 +20），不做日常送礼刷 |
| 影响 | 好感度高的伙伴，会告诉你更多人生私密片段（解锁全景图更多分支） |
| 衰减 | 长期不见（如你进城 10 年）会衰减，回乡重逢有"陌生感"剧情 |

### 6.3 好感度与全景图

- 好感度低的伙伴，玩家只能看到他的"公开人生"（打工/结婚这些公开事）
- 好感度高的伙伴，玩家能看到他的"私密人生"（抑郁/家暴/挣扎这些不为人知的事）
- **这给了玩家"想再玩一次把好感刷高"的动机**，间接增加多周目动机

### 6.4 好感度的边界

**重要：好感度不决定伙伴的"人生版本"。** 小刚是当兵还是进局子，与他跟你的好感度无关——这由命运（随机）决定。你的好感度只决定你"能看到多少"。

> 这个设计呼应了游戏哲学：**你无法改变别人的命运，你只能选择亲近还是疏远。**

## 七、伙伴线与玩家线的交织

### 7.1 伙伴事件影响玩家

伙伴的人生节点，有时会**请求玩家参与或选择**：

| 场景 | 玩家的选择 | 影响 |
|------|----------|------|
| 小刚被高年级欺负 | 帮他/旁观/一起被欺负 | 好感 + 玩家心理/社交 |
| 小芳被家里逼婚 | 帮她逃/劝她从/旁观 | 好感 + 小芳版本可能切换 |
| 阿强跑运输缺钱 | 借钱（影响玩家金钱）/拒绝 | 好感 + 金钱 |
| 丽丽高考失利 | 安慰/嘲讽/无感 | 好感 + 心理 |
| 小梅被欺负 | 挺身而出/旁观 | 好感 + 小梅版本 |

### 7.2 玩家事件影响伙伴

反过来，玩家的选择也可能影响伙伴：

- 玩家考上一本，丽丽（学习好的）可能因此更努力或嫉妒
- 玩家进城发展，小芳可能因此"死心"远嫁
- 玩家留在镇上，可能成为伙伴中"留下的人"

### 7.3 交织的边界

**但交织有限度：** 玩家不能"拯救"伙伴的全部命运。你可以借钱给阿强，但救不了他若注定残疾的命运。**这呼应了"命运不可完全改变"的哲学。**

## 八、对话系统设计

### 8.1 对话类型

| 类型 | 触发 | 内容 |
|------|------|------|
| **日常闲聊** | 走近 NPC 按 E | 天气、闲话、口头禅（填充生活感） |
| **剧情对话** | 关键节点 | 推进伙伴线（如告别、重逢） |
| **选择对话** | 关键事件 | 玩家做选择，影响好感/数值 |
| **打听** | 主动询问其他 NPC | 间接了解不在场伙伴的近况 |

### 8.2 对话风格

延续原设计的"克制、真实、不煽情"：
- ❌ 不写"小明开心地说：哇！今天天气真好！"
- ✅ 写"小明：'走，去河边。' 头也没回。"

### 8.3 推荐工具

**使用 Godot 的 Dialogic 插件**（免费开源）：
- 支持分支对话、变量、条件
- 支持角色立绘、打字机效果
- 支持 JSON 导入，便于数据驱动
- 比自研省 2-3 周

## 九、NPC 在小镇的日程

### 9.1 日程系统（让小镇有"活人感"）

每个 NPC 有自己的日程，按日内时间在小镇不同位置：

**小刚日程示例（童年版）：**

| 时间 | 位置 | 状态 |
|------|------|------|
| 早晨 | 家（小刚家） | 准备上学 |
| 上午 | 学校门口 | 等你一起进校 |
| 下午 | 学校操场 | 踢球/打架 |
| 傍晚 | 河边/老槐树 | 找你玩 |
| 夜晚 | 家 | 睡觉 |

### 9.2 日程随阶段变化

伙伴的日程反映他的人生状态：

- 小刚辍学后：白天出现在网吧/桥边，不再在学校
- 小芳远嫁后：从镇上消失，日程清空
- 阿强跑运输后：很少在镇上，偶尔凌晨出现

**日程的"空缺"本身就是叙事。**

## 十、MVP 的 NPC 范围（明确边界）

### 10.1 MVP 只做这些 NPC

| NPC | MVP 范围 |
|-----|---------|
| **小刚** | 完整童年到 18 岁告别（版本A：打工路线） |
| **小芳** | 童年到 18 岁（基础版，无恋爱线） |
| **妈妈** | 全程在场（童年少年） |
| **爸爸** | 童年在场/少年可能外出（写死一条线） |
| **王老师** | 学校场景对话 |

**大壮、阿强、丽丽、小梅、张大爷在 MVP 中暂不实现**，留到 M2/M3。

### 10.2 MVP NPC 版本规则

MVP 阶段，伙伴版本**写死**，不随机：
- 小刚固定走版本A（打工）
- 小芳固定走基础版（平凡长大）
- 父母状态固定（写死一种家庭情况）

**真正的"多版本随机"在 M3 实现。**

### 10.3 MVP NPC 的目的

验证：
- ❓ 在小镇走动能遇到有"活人感"的伙伴吗？
- ❓ 小刚 15 岁告别去打工的场景，能否打动玩家？
- ❓ 玩家会不会想"如果当时我多陪陪小刚"？

## 十二、从"写死"到"数值驱动"的演进路径

### 12.1 阶段一：MVP（写死）

- 每个伙伴固定 1 个版本
- 时间线写死在 JSON
- 无随机

### 12.2 阶段二：多版本随机（M3）

- 每个伙伴有多个预设版本
- 周目开始时按权重随机抽
- 玩家在该周目见证抽到的版本

### 12.3 阶段三：数值驱动（M5 之后，远期）

- 伙伴也跑简化版六大数值（金钱/心理/健康/社交/教育/幸福）
- 伙伴的数值根据家庭背景初始化
- 时间推进时，伙伴数值也演变
- 数值达到阈值触发伙伴的"分支事件"（如心理<30 触发"误入歧途"）
- **真正动态生成人生，而非预设版本**

> 阶段三是理想态，但工作量大。MVP 和大部分开发期用阶段一/二即可。**不要一开始就追求阶段三，会拖垮项目。**

## 十三、伙伴与全知模式的联动

### 13.1 全知模式中的伙伴展示

进入全知模式后，玩家可以：

1. 点开任何一个伙伴
2. 看到该伙伴的**所有人生版本**（已见证的高亮，未见证的可预览）
3. 看到每个版本的关键事件、情感关键词、结局
4. 理解"同一个起点，可以有这么多种命运"

### 13.2 全知模式的情感高潮

**建议在全知模式中设计一个"群像 CG"时刻：**

> 画面渐暗，老槐树下出现所有伙伴的剪影——
> 小刚、小芳、阿强、丽丽、大壮、小梅——
> 他们的不同人生版本在画面中快速闪过——
> 然后画面定格，只有一句旁白：
>
> **"每个人都有自己的命。你也一样。"**

这是游戏最强的情感爆发点，也是"命运全景"主题的具象化。

## 十四、风险登记

| 风险 | 应对 |
|------|------|
| 伙伴版本写太多，工作量爆炸 | MVP 严格只做 1 版本，后续迭代加 |
| 伙伴线抢了玩家线的戏 | 伙伴事件占比不超过 40%，主线始终是玩家 |
| 对话文案工作量巨大 | MVP 只做小刚告别等 3-5 个关键场景，其余日常用模板生成 |
| 多版本导致 bug 多 | 数据结构清晰，写自动化测试验证时间线一致性 |
| 玩家不关心 NPC | 前期用强情感场景（小刚告别）建立羁绊 |

---

## 十五、本节小结

NPC 伙伴系统是《命》从"小镇生活游戏"升级为"命运全景游戏"的关键：

- 6 个童年伙伴，每人 3-5 个预设人生版本
- 玩家在不同周目见证同一伙伴的不同命运
- 好感度决定玩家能看到伙伴多少私密人生
- 全知模式中，所有伙伴的所有版本一览无余——这才是"看遍所有人生"

**一句话：你的伙伴们的命运，是命运全景图里最有血有肉的内容。**
