# 04 - 人生阶段详解：青年（18-30岁）

---

## 一、大学/初入社会（18-22岁）

**核心体验：** 你以为成年了就自由了，其实成年是另一种枷锁

### 1.1 场景分化

#### 场景A：上了大学

**大学类型：**

| 大学类型 | 条件 | 影响 |
|---------|------|------|
| 985/211 | 高考成绩>85 | 教育+30, 就业+30, 人脉+20 |
| 普通一本 | 高考成绩>70 | 教育+20, 就业+20, 人脉+10 |
| 二本 | 高考成绩>50 | 教育+10, 就业+10, 人脉+5 |
| 三本/民办 | 高考成绩>35 | 教育+5, 就业+5, 人脉+3 |
| 专科 | 高考成绩>20 | 教育+3, 就业+3, 人脉+2 |
| 出国留学 | 家庭阶层>80 | 教育+25, 视野+30, 人脉+20 |

**专业选择（影响职业方向）：**

| 专业大类 | 典型专业 | 就业前景 | 起薪范围 |
|---------|---------|---------|---------|
| 计算机/IT | 软件工程、计算机科学 | 好 | 8k-25k |
| 金融/经济 | 金融学、经济学 | 较好 | 6k-15k |
| 医学 | 临床医学、口腔 | 稳定但周期长 | 前期低，后期高 |
| 师范/教育 | 教育学、学科教育 | 稳定 | 4k-8k |
| 工程/制造 | 机械、电气、土木 | 一般 | 5k-10k |
| 文科/艺术 | 中文、新闻、设计 | 较难 | 4k-8k |
| 管理/商学 | 工商管理、市场营销 | 一般 | 5k-10k |
| 法学 | 法学 | 难，但上限高 | 4k-12k |
| 理学 | 数学、物理、化学 | 看方向 | 5k-12k |

#### 场景B：没上大学

**直接进入社会的路径：**

| 路径 | 条件 | 影响 |
|------|------|------|
| 学技术（汽修、厨师、美容等） | 家庭支持 | 技能+15, 收入渐增 |
| 进工厂 | 无特殊条件 | 收入稳定但低 |
| 当服务员/销售 | 无特殊条件 | 收入不稳定 |
| 跟着亲戚做生意 | 有亲戚带 | 可能好也可能差 |
| 在家待着 | 家庭条件允许 | 浪费时间 |
| 走歪路（赌博/借贷/犯罪） | 心理+环境 | 可能毁掉一生 |

### 1.3 毕业选择

**这是人生的第一个重大选择。**

| 选择 | 条件 | 影响 |
|------|------|------|
| 直接就业 | 无特殊条件 | 早赚钱，但起点可能低 |
| 考研 | 学业>60 | 延迟2-3年，学历提升 |
| 考公/考编 | 无特殊条件 | 稳定，但竞争激烈 |
| 出国留学 | 家庭阶层>70 + 学业>60 | 视野+20, 但花费大 |
| 创业 | 有想法+有资源 | 高风险高回报 |
| 继承家业 | 家庭阶层>80 | 稳定 |
| 啃老/待业 | 各种原因 | 浪费时间 |

## 三、恋爱婚姻（25-30岁）

**核心体验：** 你以为爱情是美好的，但婚姻是现实的

### 3.1 恋爱系统

**恋爱可能性：**

```
恋爱可能性 = 外貌 + 经济条件 + 社交圈 + 性格 + 运气
```

**恋爱方式：**

| 方式 | 概率 | 说明 |
|------|------|------|
| 自然认识 | 25% | 同学/同事/朋友介绍 |
| 相亲 | 30% | 父母/亲戚安排 |
| 网络交友 | 20% | 交友软件/社交平台 |
| 工作中认识 | 15% | 同事/客户 |
| 其他 | 10% | 各种偶然 |

**恋爱事件：**

| 事件 | 概率 | 影响 |
|------|------|------|
| 遇到对的人 | 20% | 心理+20 |
| 遇到错的人 | 15% | 心理-15 |
| 被分手 | 15% | 心理-20 |
| 分手 | 10% | 心理-10 |
| 谈了很久 | 25% | 心理+10 |
| 异地恋 | 15% | 心理-5, 考验 |
| 被催婚 | 40% | 心理-5 |

### 3.2 结婚决策

**结婚考量因素：**

| 因素 | 说明 |
|------|------|
| 经济条件 | 有房吗？有车吗？存款多少？ |
| 家庭背景 | 对方家庭怎么样？ |
| 性格 | 合得来吗？ |
| 外貌 | 喜欢吗？ |
| 未来规划 | 有共同目标吗？ |
| 父母意见 | 父母同意吗？ |

**结婚选择：**

| 选择 | 条件 | 影响 |
|------|------|------|
| 结婚（门当户对） | 经济条件匹配 | 稳定+15, 压力+10 |
| 结婚（高攀） | 经济条件差距大 | 压力+20, 可能离婚 |
| 结婚（下嫁） | 经济条件差距大 | 心理失衡-10 |
| 不结婚 | 社会压力承受力>60 | 自由+20, 孤独+15 |
| 晚婚（30+） | 各种原因 | 选择范围缩小 |

**婚姻事件：**

| 事件 | 概率 | 影响 |
|------|------|------|
| 婚姻幸福 | 25% | 幸福+25 |
| 婚姻平淡 | 40% | 无明显影响 |
| 经常吵架 | 20% | 心理-15 |
| 出轨 | 8% | 心理-30, 可能离婚 |
| 离婚 | 12% | 心理-20, 金钱-20 |
| 家暴 | 5% | 心理-30, 健康-20 |

**买房选择：**

| 选择 | 条件 | 影响 |
|------|------|------|

| 事件 | 概率 | 影响 |
|------|------|------|

**生不生孩子？什么时候生？**

| 选择 | 条件 | 影响 |
|------|------|------|
| 早点生（25-28） | 结婚早 | 经济压力大, 但恢复快 |

## 四、职业发展（25-30岁）

**核心体验：** 你以为努力就会有回报，但现实是大多数人的努力不会有回报

### 4.1 职业路径

**程序员/互联网行业：**

| 阶段 | 年龄 | 薪资范围 | 状态 |
|------|------|---------|------|
| 初级 | 22-25 | 8k-15k | 学习成长 |
| 中级 | 25-28 | 15k-25k | 独立负责 |
| 高级 | 28-32 | 25k-40k | 带团队 |

| 行业 | 发展路径 | 特点 |

| 公务员 | 科员→副科→正科→... | 稳定，慢 |

## 五、青年阶段总结

### 这个阶段的核心矛盾

1. **理想与现实的矛盾**：你想要的生活 vs 你能过的生活
2. **自由与责任的矛盾**：你想自由 vs 你要承担责任
3. **个人与家庭的矛盾**：你想为自己活 vs 你要为家庭活
4. **现在与未来的矛盾**：你想享受现在 vs 你要为未来储蓄

### 这个阶段的关键节点

1. **毕业选择**：就业/考研/考公/留学/创业
2. **第一份工作**：决定职业起点
3. **恋爱结婚**：决定家庭形态
4. **买房**：决定经济压力
5. **生育**：决定生活重心
