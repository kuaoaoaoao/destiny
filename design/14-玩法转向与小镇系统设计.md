# 14 - 玩法转向与小镇系统设计（v0.3 核心转向）

> ⭐ 本文档是 v0.3 玩法转向的纲领性文件，定义了游戏从"纯文本选择"转向"星露谷式 2.5D 小镇生活"后的所有核心系统。后续开发以本文档为准。

---

## 一、为什么要转向

### 1.1 原设计的问题

原《命》设计（v0.2）是一款**纯文本叙事 + 选择**的人生模拟：
- 玩家读旁白 → 弹窗选择 → 数值变化 → 下一段旁白
- 单次人生 30-60 分钟，靠多周目看遍命运

**潜在风险：**
- 纯文本选择，沉浸感弱，容易像"做题"
- 弹窗事件频繁打断，出戏
- 单次人生信息密度高但玩法单一，撑不起 5-20 次多周目
- 玩家缺少"在场感"，无法与角色共情

### 1.2 转向的核心收益

| 维度 | 原纯文本方案 | 新 2.5D 小镇方案 |
|------|------------|----------------|
| 沉浸感 | 弱（读文做题） | **强（在场生活）** |
| 玩法丰富度 | 单一（选择） | **多（移动+对话+NPC+小游戏+收集）** |
| 情感代入 | 旁白告知 | **亲眼见证伙伴命运** |
| 多周目动机 | 看不同文本 | **看小镇不同版本、不同人不同命** |
| 美术成本 | 低 | 高（但有像素/复用方案控制） |

### 1.3 转向后保留不变的核心

转向的是**表现形式**，不变的是**哲学内核**：

- ✅ 保留：六大数值、命运之骰、命运之书、命运全景图、全知模式、多结局、人生各阶段、克制的情感设计
- ✅ 保留："没有好坏结局，只有不同的结局"的哲学
- 🔄 转变：事件从"弹窗"变为"小镇生活触发"；叙事从"旁白"变为"在场体验 + NPC 对话"
- ➕ 新增：可操控角色、小镇地图、NPC 平行人生、小游戏、CG

**一句话总结转向：**
> 把"读人生"变成"过人生"——但底层的命运系统、全景图、全知模式全部保留并强化。

## 二、游戏舞台：乡村 - 小镇 - 城市

### 2.1 三层舞台结构

游戏世界按人生阶段展开为三层舞台，**情感重心始终在乡村/小镇**：

```
┌─────────────────────────────────────────────────┐
│  乡村（出生的家）  ←── 童年/少年/老年的归处      │
│       │                                         │
│       │ 步行/骑车                               │
│       ▼                                         │
│  小镇（学校/集市/伙伴家）  ←── 全程社交中心      │
│       │                                         │
│       │ 青年后乘火车/大巴                       │
│       ▼                                         │
│  城市（公司/出租屋/相亲角）  ←── 青年/中年主战场 │
└─────────────────────────────────────────────────┘
```

### 2.2 各舞台定位

| 舞台 | 定位 | 出现阶段 | 玩家停留比例 |
|------|------|---------|------------|
| **乡村（家）** | 出生地、根、情感锚点 | 童年全程 + 少年周末/假期 + 青年回乡 + 老年归处 | 约 40% |
| **小镇** | 社交、学校、伙伴、集市 | 童年/少年上学 + 全程回访 | 约 35% |
| **城市** | 拼搏、压力、现实 | 青年/中年（部分出身） | 约 25% |

### 2.3 舞台与出身的关系（重要）

**主角的家一定在乡村**，但家境不同：

| 出身 | 老家条件 | 小镇关系 |
|------|---------|---------|
| 贫困家庭 | 土坯房/漏雨/爷爷奶奶留守 | 镇上的人偶尔帮衬，但也有些疏远 |
| 农村普通 | 自建房/院子/父母在或外出打工 | 镇上熟人社会，有发小 |
| 城镇普通 | 乡村但条件尚可，或镇上租房 | 镇上的孩子，关系普通 |
| 城市中产 | 乡村"老家"+城里也有房，假期回乡 | 镇上有亲戚，但略显格格不入 |
| 富裕家庭 | 乡村是"祖宅"，城里有大房 | 偶尔回乡，镇上的人客气而疏远 |

> 设计意图：把"家"固定在乡村，让所有出身的玩家都有共同的"根"的情感锚点，**但家境差异让每次回乡的感受不同**——这是命运分层的最直观体现。

## 三、小镇地图设计

### 3.1 小镇核心布局（永久不变，随阶段换皮）

小镇是一个固定的"舞台"，核心地标不变，**随人生阶段演变外观与氛围**：

```
                    ┌──────────────┐
                    │   小  学     │  ← 童年/少年主场景
                    │ （→ 中学扩建）│
                    └──────┬───────┘
                           │
        ┌──────────────────┼──────────────────┐
        │                  │                  │
   ┌────┴────┐       ┌─────┴─────┐      ┌─────┴────┐
   │ 小卖部  │───────│ 镇口老槐树 │──────│  村委会  │
   │（大壮家）│       │ （伙伴聚集）│      │  广场    │
   └─────────┘       └───────────┘      └──────────┘
        │                  │                  │
        │              ┌───┴───┐              │
        │              │ 桥/河边│              │
        │              │（抓鱼） │              │
        │              └───────┘              │
   ┌────┴────┐                          ┌─────┴────┐
   │  伙伴家  │       ←—— 道路 ——→       │  诊所   │
   │ 住宅区   │                          │（→医院）│
   └─────────┘                          └──────────┘
                           │
                    ┌──────┴───────┐
                    │  车站/路口   │  ← 青年通往城市
                    │ （出村/回村） │
                    └──────────────┘
```

### 3.2 地标随人生阶段演变

| 地标 | 童年 | 少年 | 青年 | 中年 | 老年 |
|------|------|------|------|------|------|
| **老槐树** | 挂着秋千，伙伴们玩耍 | 刻了字，秘密基地 | 老了点，秋千拆了 | 树还在，人散了 | 树又粗了，成了回忆点 |
| **小卖部** | 大壮家，热闹 | 还在，货少了 | 可能关门/转让 | 可能变快递点 | 可能没了 |
| **小学** | 在这里上学 | 搬到中学了 | 路过会看一眼 | 孩子可能在这上学 | 可能废弃/翻新 |
| **车站** | 爸妈从这里走 | 同学从这里离开 | **你从这里走/回** | 接送孩子 | 看着别人走 |

> **核心情感符号：老槐树。** 贯穿全游戏，是"时间流逝"和"命运见证"的视觉锚点。MVP 必须实现。

### 3.3 室内场景（节点性进入）

通过触碰场景入口（门/路口）切换到室内：

| 室内场景 | 功能 | 阶段 |
|---------|------|------|
| **家（你的）** | 睡觉推进时间、家庭事件、父母对话 | 全程 |
| **教室** | 上课、考试小游戏、同学事件 | 童年少年 |
| **伙伴家** | 拜访、触发伙伴线 | 童年起 |
| **小卖部** | 买东西、打听消息、大壮线 | 全程 |
| **出租屋/公司** | 城市生活、加班小游戏、相亲 | 青年中年 |
| **医院** | 父母生病、自己看病、生死事件 | 中老年 |

## 四、时间系统

### 4.1 双层时间

游戏有**两层时间**，对应两层玩法：

| 层级 | 单位 | 推进方式 | 用途 |
|------|------|---------|------|
| **日内时间** | 一天 | 实时流逝（1 天 ≈ 3-5 分钟） | 小镇探索、NPC 遇见、事件触发 |
| **人生年龄** | 一岁 | 关键事件后推进 | 阶段切换、数值演变、命运走向 |

### 4.2 时间推进规则

**日内时间（自由探索）：**
- 玩家在小镇自由行动，时间实时流逝
- 一个"游戏日"=3-5 分钟现实时间，分早晨/白天/傍晚/夜晚
- 夜晚回家睡觉 → 跳到次日 / 或推进到下一个"关键周"
- NPC 按日程在小镇不同位置（早市集 / 白天学校 / 傍晚老槐树）

**人生年龄（节点推进）：**
- 大部分日子是"日常生活"，快速跳过（蒙太奇）
- 到达**人生节点**（7 岁/12 岁/18 岁/22 岁/28 岁/35 岁/45 岁/60 岁/去世）时，进入"剧情日"
- 剧情日：玩家自由探索 + 触发关键事件 + 做重大选择

### 4.3 节奏控制（重要）

**不能让玩家每一岁都手动过 80 年！** 必须有节奏压缩：

```
童年（0-6）：纯观看，快速蒙太奇（出生设定决定画面）
童年（7-12）：每个"关键年"玩 1-2 天，其余跳过
少年（12-18）：每 2-3 年玩 1-2 天，重点在初三/高三
青年（18-30）：每年关键节点玩 1-2 天（毕业/工作/相亲）
中年（30-50）：重大事件触发才玩，其余蒙太奇
老年（50-80）：慢节奏，回望感
```

**MVP 只实现：** 童年关键日（7、12 岁）+ 少年关键日（15、18 岁高考）+ 青年关键日（22、28 岁）。每段 1-2 天，总计单次人生 30-50 分钟。

## 五、角色操控

### 5.1 操控方式

- **视角**：俯视角 2.5D（类似星露谷的俯视斜 45°）
- **移动**：方向键/WASD，四方向行走
- **交互**：走近物体/NPC 按"互动键"触发
- **菜单**：呼出命运之书/数值/存档

### 5.2 主角角色

| 年龄段 | 体形 | 行走速度 | 默认姿态 |
|--------|------|---------|---------|
| 童年 | 小 | 慢、蹦跳 | 活泼 |
| 少年 | 中 | 正常 | 偶尔低头 |
| 青年 | 标准偏瘦 | 正常偏快 | 步伐急 |
| 中年 | 标准偏沉 | 正常偏慢 | 微弯 |
| 老年 | 佝偻 | 慢 | 拖步 |

### 5.3 角色立绘（无面部特征）

延续原设计"不画具体五官，让玩家代入"的原则，但在 2.5D 中体现为：
- 行走 sprite：背影/侧影为主，偶尔正面但无明确五官
- CG 大图：关键场景给主角留白（背对镜头/低着头），让玩家代入

## 六、核心玩法循环

### 6.1 单日循环（自由探索）

```
早晨醒来（家里）
    │
    ▼
自由行动（去学校/找伙伴/去集市）
    │  ┌── 遇到 NPC → 对话/事件
    │  ├── 进入场景 → 小游戏/家庭事件
    │  └── 时间流逝（早→午→晚）
    ▼
夜晚回家睡觉
    │
    ▼
次日 / 或推进到下一关键周
```

### 6.2 人生循环（多周目）

```
出生（命运之骰）
    ↓
童年/少年/青年/中年/老年（小镇生活 + 节点选择）
    ↓
去世 → 命运之书
    ↓
命运全景图（回看这一生所有分叉 + 伙伴的人生）
    ↓
再活一次（不同出身/选择）
    ↓
重复 N 次（建议 5-8 次解锁全知）
    ↓
全知模式（看遍所有人生 + 做最终选择）
    ↓
我的人生（专属命运之书）
```

### 6.3 三层玩法融合

| 层 | 来源 | 内容 |
|----|------|------|
| **小镇生活层** | 星露谷 | 走动、探索、遇 NPC、收集 |
| **人生节点层** | 中国式家长 | 高考/相亲/裁员等重大选择 |
| **命运系统层** | 原《命》 | 六数值、全景图、全知模式 |

## 七、小游戏设计（克制使用）

### 7.1 设计原则

- ✅ 小游戏**融入剧情**，不是独立的休闲玩法
- ✅ 小游戏结果**直接喂给六大数值**
- ✅ 关键节点才有小游戏，不是天天玩
- ❌ 不做"种田/钓鱼/挖矿"这类长线养成（抢戏）

### 7.2 小游戏清单

| ID | 阶段 | 名称 | 玩法 | 数值影响 |
|----|------|------|------|---------|
| MG01 | 童年 | 抓知了/鱼 | 反应点击 | 心理+、社交+（与伙伴） |
| MG02 | 少年 | **中考/高考答题** | 限时选择题（基于教育数值） | **教育数值大变** |
| MG03 | 少年 | 偷偷玩游戏 | 节奏点击 | 心理+、教育- |
| MG04 | 青年 | **面试** | 对话选择 + 反应 | 金钱+、心理± |
| MG05 | 青年 | 加班 | 重复点击/忍耐计量 | 金钱+、健康- |
| MG06 | 青年 | **相亲对话** | 选择话题 | 婚姻线推进 |
| MG07 | 中年 | 陪孩子写作业 | 教学/选择 | 家庭关系 |
| MG08 | 中年 | 跑医院照顾 | 时间分配 | 健康、家庭 |
| MG09 | 老年 | 散步/下棋 | 轻度 | 心理+ |

### 7.3 高考小游戏（重点设计示例）

**这是少年期最关键的小游戏，决定教育数值走向：**

- 进入高考日 → 触发特殊场景（考场）
- 连续 5-10 道题（语数英理化），限时每题 15 秒
- 题目难度根据玩家教育数值生成（教育高 → 题目对玩家而言"容易"，体现积累）
- 答题结果 → 计算分数 → 决定能报的志愿 → 影响大学层次
- **但也要留随机性**：高考发挥失常/超常（±15% 浮动），呼应"命运不可控"

## 八、事件系统的改造

### 8.1 事件不再"弹窗"，改为"场景触发"

原设计的 222 个事件，全部改造为**有触发位置/触发条件的小镇事件**：

| 原触发 | 新触发 |
|--------|--------|
| 概率弹窗 | 走进某场景 + 条件满足 |
| 强制打断 | 玩家主动接近触发 |
| 文字描述 | 场景画面 + NPC 对话 |

### 8.2 事件触发方式分类

| 方式 | 说明 | 例子 |
|------|------|------|
| **位置触发** | 走进特定区域 | 走进操场角落 → 被欺负事件 |
| **NPC 触发** | 走近某 NPC | 走近哭泣的小芳 → 触发她的事件 |
| **时间触发** | 到达某时刻/日期 | 高考前夜自动触发 |
| **数值触发** | 数值达标 | 金钱<20 → 回家触发"父母吵架欠债" |
| **伙伴线触发** | 伙伴人生线推进 | 小刚"去打工"时自动播过场 |

### 8.3 事件数据结构（数据驱动，详见 13 号文档）

事件全部用 JSON 定义，包含触发位置/条件/选项/影响。**这是开发地基，必须最早做。**

## 九、美术与音频方向（2.5D 扁平手绘）

### 9.1 美术风格：扁平手绘 2.5D

| 维度 | 规格 |
|------|------|
| **风格** | 扁平手绘插画，暖色调，绘本质感（详见 16 号文档） |
| **视角** | 俯视斜 45°（2.5D isometric） |
| **生成方式** | **AI 生成**（即梦/可灵/通义/Midjourney） |
| **动画方案** | MVP 四方向静帧；完整版 Spine 骨骼动画 |
| **色彩** | 延续原设计：童年暖黄 → 中年深灰 → 老年暖灰 |
| **角色** | 主角无明确五官（代入感），NPC 有特征（辨识） |
| **场景** | 多层（地面/物体/前景）+ 窗户光影符号 |

> ⚠️ v0.3 更新：原"48px 像素"方案已废弃，改为"扁平手绘 2.5D + AI 生成"。理由：AI 生成扁平插画一致性远高于像素，且无需逐帧手绘动画。**所有美术生成规范以 16 号文档为准。**

### 9.2 MVP 美术策略：AI 生成

**MVP 阶段直接用 AI 生成正式素材（不是占位）：**

| 资源 | MVP 来源 | 完整版处理 |
|------|---------|-----------|
| 场景 | AI 生成（扁平手绘 2.5D） | 同风格补充城市场景 |
| 角色 | AI 生成立绘 + 四方向静帧 | 升级 Spine 骨骼动画 |
| NPC | AI 生成 | AI 生成全部 10 个 + 多版本变体 |
| CG | AI 生成 | AI 生成全部 20-30 张 |
| UI | 纯代码绘制 + AI 图标 | 精修 |
| 字体 | 思源宋体 + 思源黑体（免费可商用） | 保持 |

> **生成顺序见 16 号文档第九节**：先做 3 张（小镇主图 + 主角立绘 + 小刚立绘）验证风格，定下"基础脸/基础场景"再批量生成。

### 9.3 音频（沿用原 12 号文档方向）

- 钢琴为主 BGM，每阶段一首
- 环境音（鸟叫/蝉鸣/地铁/钟表）从 freesound.org 免费获取
- 交互音效用 sfxr/kenney 生成

### 10.4 数据驱动原则（最高优先级）

**222+ 事件、10 个 NPC 人生线、10 种结局，全部用 JSON 定义，绝不在代码里写死。**

这样：
- 策划加事件/改文案/调数值，不碰代码
- 多周目的"不同人生"只是切换数据组合
- 全景图回溯能基于数据重演

数据结构详细设计见 13 号文档"数据结构规范"章节。

## 十二、全知模式解锁调整

原设计要求"体验 20 次以上"解锁全知模式，门槛过高。改为**按维度解锁**，更轻量：

### 12.1 维度解锁机制

全知模式分为若干"维度"，玩家满足任一维度的解锁条件，即可解锁该维度的全知视角：

| 维度 | 解锁条件 | 解锁后能看到 |
|------|---------|------------|
| **出身维度** | 体验过 ≥3 种不同家庭背景 | 全部 6 种出身的开局全景 |
| **性别维度** | 男性和女性各体验 ≥2 次 | 性别差异的人生全景 |
| **伙伴维度** | 见证过 ≥4 个伙伴的完整人生 | 所有伙伴的所有命运版本 |
| **结局维度** | 触发过 ≥5 种不同结局 | 全部 10 种结局的触发条件 |
| **选择维度** | 在同一节点做过 ≥3 种不同选择 | 该节点的所有分支全景 |

### 12.2 全部解锁

当 5 个维度全部解锁后，进入"完全全知模式"，可看到游戏的完整命运全景，并做最终选择。

**预计玩家在 5-8 次人生内可解锁大部分维度，10-15 次解锁全部。** 比原"20 次"更可达，但仍有探索深度。

## 十三、开发优先级（MVP 定义）

### 13.1 垂直切片 MVP（目标：验证核心乐趣）

**只做 0-18 岁，一条完整人生线，证明"小镇生活 + 命运选择"好玩。**

| 模块 | MVP 范围 |
|------|---------|
| 出身 | 只做 1 种（农村普通家庭 × 男） |
| 年龄段 | 童年（7、12 岁关键日）+ 少年（15、18 岁高考） |
| 小镇地图 | 1 张主图（家 + 学校 + 老槐树 + 小卖部 + 2 个伙伴家） |
| 角色 | 主角童年/少年 2 个 sprite |
| NPC | 2 个伙伴（小刚、小芳）+ 父母 + 1 个老师 |
| 事件 | 30-40 个核心事件（从 222 里精选） |
| 小游戏 | 高考答题（1 个） |
| 结局 | 暂无（MVP 到 18 岁结束，给"未完待续"画面） |
| 命运之书 | 基础版（关键事件 + 数值） |
| 全景图 | **MVP 不做**，留到 M3 |
| 全知模式 | **MVP 不做** |

### 13.2 MVP 必须回答的问题

做完 MVP 拿去找 5-10 个人玩，验证：

1. ❓ 在小镇走动遇伙伴，有没有"在场感"？
2. ❓ 高考小游戏的紧张感能否传达？
3. ❓ 30-40 个事件够不够撑住 0-18 岁？
4. ❓ 数值变化玩家能不能感知到"选择有重量"？
5. ❓ 玩完一遍，玩家有没有"想再玩一次看不同命运"的冲动？

**如果这 5 个问题有 3 个以上"是"，方向正确，继续投入。否则停下来调整。**

## 十四、风险登记

| 风险 | 概率 | 影响 | 应对 |
|------|------|------|------|
| 工作量翻倍导致延期 | 高 | 上线推迟 | 严格 MVP，砍内容不砍核心 |

| 像素美术找不到合适风格 | 中 | 视觉违和 | MVP 用免费占位，后期定型再批量做 |
| 事件触发条件设计复杂 | 中 | bug 多 | 数据结构清晰定义，写测试 |
| 多周目内容重复感 | 中 | 留存差 | NPC 多版本人生 + 维度解锁保证新鲜 |

## 十五、本节小结

本次转向的本质：

> **从"看人生"升级为"过人生"。**
>
> 玩家不再是读旁白做选择的旁观者，而是真正操控角色在乡村/小镇/城市中生活，亲眼见证伙伴们的命运，亲历自己的选择带来的后果。
>
> 但《命》的灵魂——六大数值、命运之骰、命运之书、命运全景图、全知模式、"没有好坏只有不同"的哲学——全部保留并被小镇生活强化。
>
> 这是一次"形式服务于内核"的升级。
